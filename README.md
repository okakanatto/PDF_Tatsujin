# PDF達人 / PDFTatsujin

PDFを読み、申込書へ書き込み、署名や注釈を加え、ページを整理し、日英スキャンを検索できるPDFにするWindowsデスクトップアプリです。文書処理はローカルで行います。自作コードは[MIT](LICENSE)、依存部品はそれぞれのライセンスです。

現在は **0.5.0-dev6 開発版**です。F01〜F08の初版基盤を維持し、M4の拡張として画像からPDF作成、PDFの画像出力、ページの余白・表示範囲調整、ヘッダー／フッター・ページ番号・透かし、しおりとリンクの編集、画質を保つ容量最適化を追加しています。M5の拡張として、パスワードで保護したPDFコピーと、フォーム入力データのXFDF読み込み・書き出し、所有者が明示的に許可した編集用コピー、文書比較、複数PDFのOCR・容量最適化、標準フォーム6種類の作成・再設計を扱います。回転・CropBox・UserUnitを含む共通描画の座標変換と、保存時の座標精度を修正しています。Meiryo UIを含む書体選択、長い日本語パス、OCRの一括反映と、参照・閲覧履歴を扱います。[ロードマップ](ROADMAP.md) · [構成](docs/ARCHITECTURE.md) · [開発手順](docs/DEVELOPMENT.md) · [貢献方法](CONTRIBUTING.md)。実行結果は版ごとのローカル報告に記録します。初版はAcrobat代替へ向けた最初の出荷範囲です。全機能同等・操作性の優越は未実証です。

## 起動

配布ZIPは全体をフォルダへ展開し、展開先の `PDFTatsujin.exe` を起動します。このREADMEと同じフォルダにexeがある場合は、そのexeを使ってください。exeだけを移動せず、DLL、plugins、assets、licensesも保持します。ソースチェックアウトからのビルドは[開発手順](docs/DEVELOPMENT.md)を参照してください。日本語フォントと日英OCRモデルを同梱しており、通常利用にPythonやTesseractの追加インストールは不要です。GitHubではソースを管理しています。バイナリの公開は配布主体のMSVC再配布資格の確認待ち、正式な一般配布品質の合格は未宣言です。[初見試用の記録欄](docs/testing/M3_FIRST_USE.md)。

## できること

- **PDF本文の文字ブロックを編集する**：「作成→PDF本文の文字を編集」で横書きブロックの置換・位置／サイズ変更・削除をプレビューして適用し、Undo／Redo、保存後の検索と再編集ができます。元の字体を保つほか、Meiryo UIなど利用可能な書体を明示選択して新しい日本語文字を埋め込めます。選択枠と寸法は変更後の字形を示します。単行と、一定の字体・行送りを持つ複数行に対応し、元と同じ行数で編集します。行数変更・段落再配置・混合字体・Form内部・縦書き・OCR等は未対応です。[操作と対応範囲](docs/design/EXISTING_TEXT_EDIT.md)・[複数行の範囲](docs/design/EXISTING_TEXT_MULTILINE.md)。
- **PDF本文の画像を編集する**：「作成→PDF内の画像を編集」で対象画像を選び、位置・サイズ・PNG/JPEGへの差替え・削除をプレビューして適用します。1回のUndoで戻し、通常PDFとして保存後も再編集できます。「グループ内の画像も表示」で対応するForm内部の画像も選べ、同じ画像やグループを共有する別の描画は保持します。グループの表示範囲に収まる配置を扱い、OCRと重なる画像、循環、透明グループ、明示クリップ、レイヤー、タグ等は理由を表示して拒否します。画像の削除は墨消しではありません。[基本の範囲](docs/design/EXISTING_IMAGE_EDIT.md)・[グループの範囲](docs/design/EXISTING_IMAGE_FORMS.md)。
- **限定した墨消しコピーを作る**：「作成→墨消ししたコピー」で実ページを拡大し、範囲を描画・移動・数値調整して、新しいPDFへ保存します。原本・未保存状態・Undoを保持します。画像だけのスキャンは、そのコピーを日英OCRして範囲外の文字を検索・コピーできます。文字列途中、範囲外の文字と字体を共有する条件、既存OCR層の部分指定等は保存せず理由を表示します。文書情報・添付等も整理されるため、適用前に確認します。一般文書の復元不能性は未実証です。[対応範囲](docs/design/REDACTION_COPY.md)・[スキャンとOCR](docs/design/REDACTION_SCAN_OCR.md)。
- **証明書で署名したコピーを作る**：「作成→証明書で署名したコピー」で、ローカルの対応PFX／P12とパスワードを指定し、証明書の名前・期間・指紋を確認してから新しいPDFへ署名します。元の未保存状態とUndo、既存フォーム、注釈、日英OCRを保持し、コピーを別ウィンドウで読み取り専用として開きます。RSA／EC・SHA-256の不可視の承認署名に対応します。既存署名への追加、タイムスタンプ・LTV・ハードウェア鍵は未対応です。[操作と対応範囲](docs/design/CERTIFICATE_SIGNING.md)。
- **証明書署名を確認する**：「作成→証明書署名を確認」で、保存済みPDFの署名対象の改変、現在のファイル全体を覆うか、証明書の現在のローカルチェーンを分けて表示します。処理中の取消、証明書の指紋・詳細のコピーに対応します。失効状態・署名時点の有効性・タイムスタンプ・文書署名用途は未評価で、作成は別の明示確認の入口で扱います。[操作と検証範囲](docs/design/CERTIFICATE_SIGNATURES.md)。
- **フォームを作る・設計する**：「作成→フォームを設計」で実ページに入力欄を描き、単行／複数行テキスト、チェック、ラジオ、コンボ、リストの名前・値・選択肢・位置・大きさを指定できます。本アプリで作った項目は通常PDFへ保存後も設計を変更でき、まとめて1回のUndoで戻せます。日本語の既定フォントを文書に共有して埋め込みます。[操作・対応範囲とフォント生成](docs/design/FORM_DESIGN.md)。
- **フォームの入力値を読み込む・書き出す**：「作成→フォーム入力データ」で、項目と値を確認してXFDFへ出力できます。読み込みは現在値との変更一覧を確認してからまとめて適用し、1回のUndoで戻せます。同じ表示ラベルでもPDFの項目名で区別し、不正値や取消では一部を反映しません。入力データは平文のファイルです。[操作と形式](docs/design/FORM_DATA.md)。
- **保護を解除した編集用コピー**：パスワードで保護された文書で「作成→保護を解除した編集用コピー」を選び、変更権限パスワードを確認して、新しいコピーへの解除を明示選択します。コピーを別ウィンドウで開いて編集できます。元の保護と読取専用は保持し、通常保存では解除しません。[操作と保持条件](docs/design/UNPROTECTED_PDF_COPY.md)。
- **パスワードで保護したコピーを作成する**：「作成」から閲覧用・変更権限用のパスワードと操作の許可を指定し、AES-256で新しいPDFへ保存します。本文・画像・署名・フォーム・日英OCRを保持し、作業中の保存先やUndo履歴は変えません。コピーを開き直した場合、本アプリでは閲覧用になります。[操作と保護の設計](docs/design/ENCRYPTED_PDF_EXPORT.md)。
- **画像からPDFを作成する**：PNG・JPEGを一覧で並べ替え、1画像を1ページにする新しい未保存文書を作成します。A4への配置または明示dpiによる画像サイズ、透明PNG、EXIF方向、進捗・中止と再試行を扱います。画像や開いているPDFを変更しません。[操作と今回の境界](docs/design/IMAGE_PDF_CREATION.md)。
- **PDFを画像へ出力する**：現在・全体・指定ページをPNG／JPEGへ書き出します。CropBox・回転・UserUnit、署名やフォームの表示を反映し、dpiと出力先を指定できます。既存の画像を上書きせず、中止・競合は個別結果に示します。PDFの文字・フォーム等の情報は画像へ引き継がれません。[操作と今回の境界](docs/design/PDF_IMAGE_EXPORT.md)。
- **余白・表示範囲を調整する**：ページ整理で複数ページを選び、回転後の上下左右から除く長さをmmで指定します。プレビューの青枠内を残し、1回のUndoで戻せます。本文・画像・注釈・フォームはPDF内に保持されるため、墨消しには使えません。[操作と保持の設計](docs/design/PAGE_CROP.md)。
- **ヘッダー／フッター・ページ番号・透かしを配置する**：「作成」メニューで対象ページ、文字、書体、サイズ、四辺の距離を指定し、プレビューを確認して適用します。ページ番号は `{page}`、総ページ数は `{pages}`。透かしは角度・不透明度も指定できます。各設定を1回のUndoで戻し、通常PDFへ保存後も設定ごとに変更・削除できます。[操作と保持の設計](docs/design/PAGE_DECORATIONS.md)。
- **しおりを編集する**：左の「しおり→しおりを編集」で、追加、名前変更、順序・階層・移動先の変更、子を含む削除ができます。既存の位置・倍率・色・アクションは保持し、移動先を明示変更した場合だけ指定ページ全体へ置き換えます。候補をまとめて1回のUndoで反映し、通常PDFへ保存後も再編集できます。[操作と保持の設計](docs/design/BOOKMARK_EDITING.md)。
- **リンクを編集する**：「作成→リンクを編集」で実ページ上の範囲を描き、移動・サイズ・説明・文書内ページ／Web URLを指定できます。既存の宛先は選び直すまで保持し、通常PDFへ保存後も変更・削除できます。文書への適用は1回のUndoで戻せます。外部URLを自動で開きません。[操作と保持の設計](docs/design/LINK_EDITING.md)。
- **PDFの容量を最適化する**：「作成→PDFの容量を最適化」で、現在の文書を通常保存した場合と最適化した場合のサイズを比較します。文字・画質・再編集性を維持し、候補が小さくなった時だけ文書へ適用できます。1回のUndo、処理中の取消を扱い、ファイルの保存は既存の保存操作で行います。[操作と今回の境界](docs/design/PDF_OPTIMIZATION.md)。

「作成→PDFを比較」は現在の未保存状態と別PDFを左右に表示し、ページの追加・削除、72dpiでの見た目、抽出文字、対応フォーム値、注釈・リンク、しおりと文書情報を読み取り専用で照合します。共通ページ／ページ番号の対応を選び、結果を新しい平文JSONへ出力できます。添付ファイル・スクリプト・タグ構造・XFA等は比較の対象外です。[操作と今回の境界](docs/design/DOCUMENT_COMPARISON.md)。

「作成→複数PDFをまとめて処理」は保存済みのPDFを順にOCRまたは容量最適化し、新しいPDFへ出力します。元の入力・現在の文書・Undoを保持し、保存済み・処理不要・失敗・取消・未処理を個別に表示します。途中で中止しても保存済みの出力は残します。既存出力は上書きしません。[操作と今回の境界](docs/design/BATCH_PROCESSING.md)。

- **読む**：連続スクロール、ページ縮小画像、ページ番号・しおり、幅／全体に合わせる、ポインターを基準にしたズーム、手のひら移動、前の表示へ戻る、検索結果への移動、ページをまたいだ文字選択・コピー、印刷。
- **書き込む・署名する**：日本語テキスト、固定日付、PNG/JPEG画像、文字・画像署名。配置、移動、文字・書体・色・サイズ変更、削除、Undo／Redo、通常PDFへの保存と再編集。Meiryo UIなど利用PCで使える書体と同梱Notoを選べます。再利用する署名だけを明示的にローカル保存できます。
- **注釈する**：本文を選択したハイライト、コメント、矩形、直線、矢印。標準PDF注釈と外観情報を保存し、追加した注釈を再編集できます。
- **フォームへ入力する**：標準AcroFormの単行／複数行テキスト、チェックボックス、ラジオボタン、コンボ／リスト選択。Tabで移動し、日本語の値と外観をPDFに保存します。
- **ページを整理する**：複数選択、ドラッグや指定位置での移動、削除、回転、別PDFのページ挿入、文書結合、抽出、範囲別・1ページずつの分割。フォーム名が衝突する結合は通知して拒否します。
- **OCRする**：日本語・英語、全体／現在／指定ページ、進捗・取消。画像・既存文字・署名・注釈・フォームを保持し、成功した結果だけを1回のUndo操作として反映します。
- **保存する**：未保存表示、別名保存、原本への上書き確認、外部変更検出。候補PDFを検査してからWindowsの置換処理を行い、失敗時は文書と未保存変更を保持します。複数出力は成功／失敗を個別に表示します。

中央にPDF、左にページ／しおり／検索、上に文書・作業操作、右に必要な設定、下に状態とページ・倍率を配置します。集中表示でも主要な閲覧操作を使えます。[閲覧UXの設計](docs/design/VIEWER_UX.md)と[性能測定の設計](docs/design/READING_PERFORMANCE.md)を参照してください。

## 対応範囲

既存本文の文字・画像とフォーム設計は、各設計文書に記した対応構造に限ります。一般段落の再配置、混合字体・縦書き・Form内の文字、任意の他社フォームの設計変更は未対応です。フォームのJavaScript計算・検証・送信やXFAの設計も対象外です。「署名」ツールは見た目の文字・画像です。証明書署名の検証・作成は別の入口で扱います。矩形を重ねる操作は墨消しではありません。保護・証明書署名・XFA等の制限を明示し、無断解除や証明書の有効性保証を行いません。

OCRの基準試験は鮮明な横書きの印刷文字です。古い縦書き・ルビ原稿では大きな誤認識を確認しました。認識結果を原文と照合してください。合成入力の数値は、一般の実文書全体に対する精度保証ではありません。クリーンWindowsでのオフライン試験、実容量不足、一部の外部ビューア・OS表示倍率、初見の第三者評価には未実行項目があります。評価版を一般配布品質の合格とは呼びません。

## 試験・開発

`fixtures/D01.pdf` は日本語・英語のデジタル文書、`D03.pdf` は日英の画像文書8ページ、`D07.pdf` は標準フォームです。合成入力と正解は固定しています。`fixtures/real-scans/manifest.json` に、実スキャンの出典・再利用条件・ハッシュとOCR前に固定した正解を記録しています。

[SPEC.md](SPEC.md)、[TECH.md](TECH.md)、[ACCEPTANCE.md](ACCEPTANCE.md) が要件・試験契約です。[M1_REPORT.md](M1_REPORT.md)、[RC2の報告](M3_REPORT.md)、[RC3の報告](M3_RC3_REPORT.md)、[RC4の報告](M3_RC4_REPORT.md)、[RC5の報告](M3_RC5_REPORT.md)、[RC6の報告](M3_RC6_REPORT.md)と `docs/testing/M1_*.md` は各版の証拠を保持します。報告の測定結果は記載された候補版にだけ適用し、ソースの現在版へ引き継いだ結果として扱いません。ソースCIは整形・固定入力・依存版を検査し、Windowsでの実行試験を代替しません。

プロジェクトの保存量上限は20GBです。依存・ビルド・配布物・証拠を含めて計測します。PDF4QTはMIT、TesseractとモデルはApache-2.0、NotoはOFL、Qtは動的リンクのLGPL-3.0構成です。[第三者部品の扱い](docs/THIRD_PARTY.md)を参照してください。
