# 公開内容の確認

ソース、ライセンス、使い方、ビルド手順、対応範囲、再現可能な試験条件と結果を公開します。個人情報、認証情報、私用ファイル、開発環境の内部記録はリポジトリへ含めないでください。

コミット前に `git diff --cached` で全文を確認し、`python scripts/check-publication.py --staged` を実行してください。PR本文とリリース説明も `--text-file <ファイル>` で検査できます。画像・PDF・Office文書などは画面や本文、メタデータ、添付を確認し、由来とSHA-256を `publication-assets.json` に記録します。機械検査の成功だけでは内容の確認を代替できません。

`git config core.hooksPath .githooks` でコミット前・送信前の検査を有効にできます。送信前は、追加される全履歴とコミット文も検査します。古い履歴を含むブランチの混入を防ぐため、検査を回避しないでください。CIでも同じ検査を実行します。
