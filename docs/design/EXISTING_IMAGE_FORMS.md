# 既存画像：共有Form内部の選択描画

現在のページ直下画像に続き、Form XObject内部の画像を移動・差替え・削除する範囲を追加する。Formは画像や文字をまとめる描画資源で、入力フォーム欄とは異なる。対象の1回の画像描画とそこへ到達するFormの呼出し経路を識別する。同じForm・画像を共有する別の呼出しへ変更を波及させない。

最初の追加範囲は有限・可逆な行列を持つ、深さ8以下・全描画1000以下の非循環FormとImage XObjectとする。明示クリップ命令、インライン画像、透明グループ、任意レイヤー・構造タグ等を対応済みと表示しない。Form固有のBBoxは保持し、変更後の画像が祖先の表示範囲を超える場合は理由を表示して拒否する。既存OCRとの交差・保護・証明書署名の既存制限を維持する。

ページ直下だけの従来経路を維持し、追加の表示範囲としてForm内部を選択する。対象の実ページ・所在・mm寸法を示し、変更後のプレビューを明示適用して1回のUndoにする。取消・古い候補・入力更新・生成失敗で部分反映しない。

保存では対象の末端Formからページまでの資源と呼出しを複製し、対象経路だけを新しい参照へ切り替える。兄弟呼出し、別ページ、文字、フォーム値・外観、注釈、元の資源・行列・BBoxと描画順序を保持する。画像資源や元のFormが未使用で残る場合があり、描画の削除は墨消しではない。通常PDFとして保存後も同じ経路で再編集する。

配置の逆操作で微小な座標誤差を積み重ねないため、生成した描画の周囲にPDFコメントで元の行列・変換・元のDoを保存する。現在の行列、限定したq/cm/Do/Qの本文と記録が一致する場合だけ利用し、外部の変更で一致しない記録は採用しない。元の配置へ戻す場合は元の描画を復元する。独自の別ファイルを表示や再編集の依存にせず、PDFium・Popplerで通常のPDFとして描画を検査する。BBoxの境界は含み、行列計算の1e-8ptのみを数値誤差として扱う。枠外0.01ptは拒否する。

実装前に、同じ外側Formの2回の描画、その内部のFormと共有画像、範囲外の文字・画像・AcroFormを含む合成入力を固定する。移動・縮小・差替え・削除、復元、Undo/Redo、保存後の再編集、BBox外・循環・非対応グループ・OCRの拒否を実行する。独立PDFエンジンで選んだ呼出しだけの変化、他の画像画素・文字位置・フォーム外観・ページ座標・範囲外画素を確認する。従来の直接画像とM1〜M6の回帰を維持する。元の受入条件・入力・正解は変更しない。
