# ページの共通座標変換

画像出力の追加検査で、回転とCropBox原点が異なるページの描画位置が独立描画と一致しないことを確認した。既存の逆変換往復だけの試験は、間違った変換でも逆行列があれば通る。既存の要件・正解・閾値は変更せず、用紙内の正しい位置を確認する試験を追加する。

共通pageMatrixはPDFのCropBox座標（y上向き）を、回転後の用紙の左上原点（y下向き）へ変換する。倍率にUserUnitを含め、CropBox四隅を用紙の四隅へ対応付ける。用紙の回転0/90/180/270度について、左上に対応するPDF点は順に(x0,y1)、(x0,y0)、(x1,y0)、(x1,y1)。四隅の全体はpageSize×倍率と一致し、両軸の物理倍率は同じになる。

実装前の検証条件：

- Geometry01：固定D02の4回転・CropBoxオフセット・UserUnitと倍率0.5/1/1.5/2。用紙境界・原点・両軸の向きと尺度を独立した期待値へ照合し、誤差0.000001pt以下。
- Geometry02：D02と同じ用紙辞書を持つ別の合成PDFへ、PDF座標の四隅に異なる色の矩形を置く。共通描画とページ一覧用描画の全画素一致を確認する。
- 独立検査：pypdfで用紙辞書、Pillowで4色の位置、Popplerで独立描画を確認。既知のPDF矩形から求めた描画位置、共通描画とPopplerの各矩形境界の差は2px以下。画像の後からの縮尺調整で一致させない。純粋なベクター矩形と可視位置で判定し、フォントの字形差に依存させない。
- 既存98件・画像出力の画素／dpi／品質／競合と独立PDF検査を再実行。失敗した元の変換と修正後のexe・結果を区別して保持する。

文書のCropBoxや本文をこの修正で書き換えない。中央ビューアの上流の描画行列と、このアプリが所有する画像・ページ一覧の行列を区別する。中央ビューアのネイティブ操作を未実行のまま合格としない。
