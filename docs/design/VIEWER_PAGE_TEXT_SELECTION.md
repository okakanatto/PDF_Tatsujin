# キーボードで現在ページの文字を選ぶ

閲覧中にマウスで長い範囲をなぞらず、現在のページの文章をコピーできるようにする。既存の範囲選択・文字キャッシュを共用し、PDFを変更せず、Undoや保存状態にも影響させない。

PDF表示領域にフォーカスがある場合、Ctrl+Aで現在ページの文字をすべて選ぶ。右クリックメニューに「このページの文字をすべて選択」を置き、対象が全文書ではなく1ページであることを示す。隣のページを右クリックした場合は、そのページを対象にする。余白やキーボードで開いたメニューは現在ページを対象にする。

解析は既存の非同期キャッシュへ依頼し、待機中はコピーを無効にする。完了後に選択を描画し、文字数とCtrl+Cを案内する。コピー権限のないPDFは拒否し、文字情報のないページはOCRを案内する。解析失敗時やEscapeで取消した後は、部分的な文字をクリップボードへ出さない。

Ctrl+Aをウィンドウ全体のショートカットにしない。検索・署名・フォームの入力欄では、その欄の文字を選ぶ。全ページの先読みを行わず、表示ページと選択した1ページだけを既存キャッシュの対象にする。全ページコピーの新規機能はこの変更の範囲外。

Shift+クリックで選択を伸ばす場合は、現在ページの先頭を起点とした通常の範囲選択へ移行する。通常クリック、新規文書、編集による版の更新、Escapeは選択を解除する。拡大縮小は完了した選択を保持する。

検証は固定済み日本語・英語の各ページ全文、右クリックの対象、非同期取消、入力欄へのフォーカス、コピー禁止、スキャン／CropBoxで文字のないページ、回転ページ、2000ページ文書での抽出ページ数を扱う。Qt offscreenでの検証とネイティブWindowsの操作評価を区別する。
