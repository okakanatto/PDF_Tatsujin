# 所有者が許可した編集用コピー（M5）

継続指示に沿う拡張設計。SPEC・TECH・ACCEPTANCEの読取専用、暗黙の平文保存禁止、試験の正解・閾値を維持する。

「作成 → 保護を解除した編集用コピー」で、変更権限パスワードを入力し、「コピーからパスワードと操作制限を取り除く」を明示選択する。初期状態は未選択で、通常の保存や開く操作では解除しない。元のウィンドウは読取専用のまま、新しい名前に保存したコピーを別ウィンドウで開く。所有者パスワードで元文書を開いていても、この操作で再確認する。パスワードは非表示が既定で、履歴・設定・ログへ記録しない。

標準のパスワード暗号化を対象に、独立したハンドラーで所有者だけを認証する。閲覧用や誤パスワードでは解除しない。空の所有者パスワードがある入力も、空の入力が所有者として認証され、利用者が解除を明示選択した場合だけ扱う。SDKの最初の空パスワード試行が、入力した別のパスワードの成功と誤認されないようにする。新規暗号化とは異なり、既存文書のパスワードには入力文書の方式の規則を適用する。[パスワードと権限の意味](https://qpdf.readthedocs.io/en/stable/encryption.html)。

証明書署名・XFA・非対応フォーム／スクリプト付きの文書は拒否する。証明書方式の暗号化は対象外として表示する。明示Cryptフィルターが残るストリームは、この単位では拒否し、データを失う変換をしない。未対応を黙って成功扱いにしない。

読み込み時に復号されたオブジェクトを保持し、トレーラーのEncryptキーを削除し、暗号化ハンドラーをNoneへ置き換える。本文・画像・署名／注釈の再編集情報・フォーム値と外観・リンク・しおり・OCR・メタデータ・ページ寸法と回転を保持し、ページの画像化をしない。既存ファイルは上書きしない。専用候補に書込み、パスワードなしで再読込検証した後、同じファイルシステム上で置換なしの原子的確定を行う。取消、書込み失敗、確定直前の競合で元文書や既存ファイルを変えない。確定後の遅い取消は保存成功として扱う。

## 実装前の試験条件

- 日本語の所有者／閲覧用・誤パスワード、AES-256とAES-128／RC4の入力を認証し、拒否時も元の認証状態とPDFを保持する。空の所有者パスワードの初期試行も検査する。旧式暗号化は入力互換性の試験のみで、新規出力では採用しない。
- 複数ページの回転・CropBox・UserUnit、署名・画像・透かし・フォーム・リンク・しおり・メタデータを復号前後で比較。独立したpypdf／PDFiumでEncryptキーなし、可視画素差0、本文・フォーム・ストリームの保持を確認する。
- 保存後のコピーで日本語署名とフォームを再編集し、Undo／Redoと通常保存を確認する。原本のハッシュと読取専用、コピー／印刷制限は変えない。
- 日英の実OCR、検索・Qtコピーを復号したコピーでも実行する。
- 実ダイアログの明示選択、パスワード表示切替、失敗・再試行・取消、コンパクト寸法、別文書の編集を実行する。既存先・原本・無効先・書込み後取消・確定直前の競合・NTFS拒否を試験する。
- 全回帰・独立検査・通信権限なし・配布物の実展開後実行を行う。ネイティブIME／OS倍率・Reader GUI・実容量不足・物理印刷・クリーンWindows・初見評価は、実行するまで未実行／未評価とする。
