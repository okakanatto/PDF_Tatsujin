# ページ一覧の縮小表示

2026-10-05。M1の閲覧設計を具体化する。SPEC・ACCEPTANCE・固定文書・閾値を変更しない。

左のページ一覧では、一覧内で見えているページを優先してサムネイルを作る。回転・CropBox・UserUnit・自作署名・既存注釈を反映する。現在ページ以外も文書を見分けられるようにし、未描画は紙の外形と「描画中」、失敗は「描画できません」を表示する。失敗を白紙の縮小画像でごまかさない。物理番号とPageLabelsは画像から独立して読み上げ・クリック・キーボード移動に使う。

行の高さは画像の準備前後で一定にする。画像は96×128論理px内へ縦横比を保持して収め、番号を下へ置く。長いラベルは省略表示とツールチップで読める。選択・現在ページは枠と背景で区別し、クリックで本文へ移動し、表示履歴から戻れる。サムネイルを描くだけでは本文位置・編集Undo・dirty・検索結果を変えない。

PDF描画は低優先度の専用ワーカーで1ページずつ行い、GUIイベントやWindow::refreshで同期描画しない。PDFの不変スナップショット、revision、要求世代、画面倍率を使い、文書変更・Undo／OCR／回転・倍率変更前の遅延結果を捨てる。QImageだけをワーカーから返し、GUI側で描画する。DPRに応じた画素数を作り、OSの倍率設定は変更しない。

キャッシュの画像部分は8MiBまで。画像を破棄した行はプレースホルダーへ戻す。全100ページを開いただけで100ページ描画せず、一覧スクロール先の見える行と現在ページを要求する。ページ一覧を閉じたときは新しい要求を止め、既に処理中の1ページは安全に完了・世代照合する。非表示中の全ページ先読みはしない。

検証はD02の縦横比・回転・切抜き、D10の100ページで初期要求数・画面応答・キャッシュ・末尾へスクロール、D01の署名追加／Undoで更新、別文書への切替中の遅延結果破棄を扱う。サムネイルを選んだ後の表示履歴と、本文スクロールに伴う現在ページの同期も確認する。Qt offscreenの倍率試験と実OS倍率は別記録にする。
