# 既存本文の文字を編集する：最初の対応範囲

既存本文の文字列を、元の文字コード・埋込み字体・文字位置を確認して変更する。追加署名で本文を覆う方式へ置き換えない。文書全体を再生成せず、選択した文字ブロック内の描画文字または位置行列だけを変更する。原本、未保存状態、未選択本文、画像、注釈、フォーム、ページ座標を保持し、明示適用で1回のUndoへ反映する。

初期対象はページ直下のBT/ET内に、明示した1個のTmと1回のTj/TJ描画を持つ横書きブロックとする。字体を維持して、符号化可能な文字への置換、位置・サイズ変更、削除を扱う。TJの字間調整は位置変更時にそのまま保持し、文字列を変更するときは選択した描画だけをTjへ置き換える。新しい文字の符号化と再解析の文字列を照合し、不明なUnicode対応や欠落文字を黙って別字にしない。現在の部分字体にない文字や別の書体への変更は初期対応に含めず、追加の字体生成として追跡する。

Form内部、縦書き、複数行・複数描画、クリップ／不可視OCR、レイヤー、タグ、非対応のテキスト位置命令や破損した文字対応は理由を表示して拒否する。既存の保護・証明書署名の編集制限を維持する。削除後に未使用字体・元コードが資源に残る場合があり、墨消しではない。

UIは実ページの候補プレビューと対象ブロック一覧、元の文字、編集する文字、mmの位置・サイズ、文字の収まりを同じ画面に示す。文字入力中に座標や文字を再整形しない。取消・処理中のEsc・元PDFの外部更新で一部を反映しない。拡大時は高解像度で描画し直す。

実装前に、共有字体の別ブロック、日英文字、文字変更前後の正解、字間調整、回転／CropBox／UserUnit、画像・フォームを持つ固定入力を準備する。変更・移動・縮小・削除、Undo/Redo、保存・再読込・再編集、原本不変、非対応拒否を実行する。独立エンジンで変更後の文字と範囲外の文字位置・画素・フォーム・画像を検査する。初期対応の成功を任意の本文編集やAcrobat同等の成立と表示しない。
