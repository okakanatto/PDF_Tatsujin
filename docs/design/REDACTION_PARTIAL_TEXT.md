# 文字列途中・既存OCR層の墨消し

2026-10-11。M5の既存コピー操作を拡張する。SPEC／TECH／ACCEPTANCEと既存の固定入力は変更しない。

対象は横書きのTj／TJ、標準書体と埋込みTrueType、軸に沿う座標変換を持つType1 Form内の同じ内容とする。文字の途中を横切る指定は引き続き拒否する。文字列の途中を指定した場合はその文字だけを除去し、連続する除去文字の進み量をまとめ、範囲外の原文字の座標を保持する。画像がある既存OCRページでは、元画像画素の除去と不可視文字の除去を同じ候補に適用する。再OCRやページ画像化で代替しない。

字体は削除対象を含む元のToUnicode・埋込み字体・CID対応を候補から切り離す。残る字形に必要なTrueTypeのglyf／loca／hmtxを新しい番号で再構築する。複合字形の構成部品だけを閉包として保持する。Unicode対応は残る文字から新規生成し、元のcmap・name・postの文字名・レイアウト表・未知の表・未使用字形を引き継がない。保持する字形にヒンティング命令がある字体はこの対応範囲では拒否し、字体全体のprep／fpgmも引き継がない。原字体と同じ字形が範囲外にも必要な場合、その字形を保持することと、削除した文字列順を残すことを区別する。

元資源への別ページ・Form・外観・未知属性からの参照や、別オブジェクトの複製は既存の到達可能性／展開ストリーム検査で拒否する。共有資源を保持したまま安全な出力としない。Form一部指定では外部参照・透明グループ・非軸変換・継承を確認できない資源・再帰上限超過を拒否する。未評価の一般文書全般への復元不能保証は行わない。

追加試験は実装前に合成PDF・削除語・保持語・文字位置・指定矩形・入力ハッシュを固定する。可視日本語、不可視OCR、Tj／TJの途中、空白・字間・水平倍率、回転／CropBox／UserUnit、部分Formと共有資源を含める。PDFium／pypdf／Popplerで対象語不在、保持語・位置、元字体／対応表の不在、字体の字形集合を検査する。実コピー画面・保存・再開・範囲外編集、取消・失敗での原本／未保存／Undo保持を実行する。既存の危険な出力の拒否、画像画素とスキャンOCRの固定試験も維持する。

旧固定入力の「非対応のため拒否」という条件は履歴として保持する。新しい対応範囲に入る入力は別の固定した追加条件で安全な出力を検査し、以前の失敗や拒否の記録を置き換えない。新しい条件の成功を既存の未実行環境試験の代替にしない。

実OCR追試の追加条件は `fixtures/redaction-copy/partial-real-ocr.json`。元D03の入力・検索語は維持する。旧矩形48／620／420／65は実際に字形を横切るため引き続き拒否する。追加した市民公園の矩形は、処理前OCRの独立字形位置で右端93を固定した。スキャンをOCR前に処理する既存矩形45／765／49／18は変更しない。実OCRの標準Device色空間と不透明な拡張描画状態は、既知の項目と値だけを新規辞書へ組み直す。透明合成・パターン・未知属性は拒否する。

低解像度画像の部分境界にある元々白い画素は白を保持し、指定範囲内の黒は最終ベクトル矩形で描く。秘密の画素値を残す方式ではなく、既知の空白画素を不要に黒くして範囲外へはみ出すのを防ぐ。非白画素と完全に対象内の画素は従来どおり除去する。既存の画像画素の独立検査条件を維持する。

字間指定を持つ追加Tj／TJ入力は、入力時点のQt抽出に挿入空白がある。Qtではその保持行の文字列を入力時点と厳密比較し、固定した保持語・位置はPDFiumとpypdfで検査する。入力・正解・位置の0.5pt条件を変更しない。独立したPDFium／Popplerの300dpi描画では、指定矩形と既存の1画素境界の外側に差分0を要求する。

追加の複合字形固定入力は `partial-composite-v3`。通常の部品とGID 0の部品を分けて検査する。未修正コードで、残る「公」の必要なGID 0部品が空になり輪郭が失われるFAILを再現した。通常は欠字用のGID 0を空にするが、残る字形に必要な場合だけ、その字形を参照閉包として解析・保持する。字形名や未使用資源は引き継がない。必要部品の輪郭と位置・範囲外画素を独立検査し、固定した条件を変えない。
