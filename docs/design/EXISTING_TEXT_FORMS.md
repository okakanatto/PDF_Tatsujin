# 共有グループ内の本文

従来のページ直下モードを維持し、「グループ内の文字も表示」を選ぶ追加経路で、対応するForm XObject内の横書き本文を扱う。実行単位ごとに文字・字体・位置・呼出し元を追跡し、選択した呼出しからページまでの枝だけを複製する。同じ資源を使う別のグループと別ページを変更しない。

対応する一定字体の文字ブロックについて、元字体での置換、許可された字体への明示変更、位置・サイズ、削除、手動の改行数・行送り変更、Undo/Redo、通常保存・再読込・再編集を扱う。先祖FormのBBox内に完全に収まる字形に限る。はみ出し・部分クリップ・透明グループ・循環・レイヤー・構造タグ・非対応文字等は理由を表示して非反映にする。文字の削除は墨消しではない。

既存の共有Form画像の固定入力を基礎に、2階層の同じ本文を2回描画し、原本・期待文字・選択する呼出し・操作を製品操作前に別の条件へ固定する。別呼出しの字体・文字・座標と全画像・フォーム・ページ座標を保持する。取消・拒否で部分変更しない。保存後の再編集とUndo/Redo、BBox境界、実UIの選択・日本語貼付け・拒否からの回復を実アプリで検査し、PDFium・pypdf・Popplerの独立検査を行う。既存の正解・閾値を変えず、一般のFormや本文編集全体の品質を先に宣言しない。
