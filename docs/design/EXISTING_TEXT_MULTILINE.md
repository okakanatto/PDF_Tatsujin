# 既存本文：均一な複数行ブロックの追加範囲

現在の単行編集に続き、ページ直下の1個のBT/ETに、先頭の1個のTm、一定の字体・サイズと行送り、T*で改行する複数のTj/TJがある横書きを扱う。位置・サイズ変更は先頭行列だけを変更し、元の行間と文字情報を保持する。文字の置換は行ごとの描画を変更し、削除は描画のみを空にする。行間に字体・サイズ・色・文字間隔・位置命令を変更するブロックはこの追加範囲へ混ぜない。

最初の置換は元と同じ行数に限定する。行数が違う場合は理由を表示して原本と未保存変更を保持する。自動折返し・段落の再配置は別の追加範囲であり、成功したと表示しない。元の字体にない文字には明示選択した許可字体を埋め込む。先頭Tmの回転・拡縮、CropBox、UserUnitを共通座標経路で扱う。行ごとの字形を検査し、はみ出し・欠落・文字コード不一致は採用しない。

UIは改行を保持する本文入力と実ページのプレビューを使い、元の行数と変更後の行数を示す。各行を確認して明示適用し、1回のUndoにする。入力中の世代更新、処理中の取消、原本の外部更新は既存の候補処理で非反映にする。複数行の1つを編集すると、他のブロック、フォーム、画像、注釈、後続の字体状態を保持する。

実装前に別の合成入力で2行の日英置換と行数、一定の22pt行送り、直後のTf省略ブロック、異なる行間の字体変更を持つ拒否入力を固定する。移動・拡縮・削除・日英置換・明示書体選択、保存後の再編集、Undo/Redo、原本不変、行数違い・混合字体の拒否を実行する。PDFium・pypdfで置換後の検索語と行、未選択文字と座標を確認し、Popplerで選択字形の範囲外画素、フォーム外観、画像を照合する。元の受入入力・正解・閾値を変更しない。
