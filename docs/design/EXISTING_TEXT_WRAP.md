# 本文の幅に合わせた折返し

既存の通常置換・手動改行を維持し、専用操作「幅に合わせて折り返す」で、対応する横書きブロックの文章を指定幅と行送りで配置する。元字体または許可された明示字体の実際のPDF字形と送り幅を使う。元の位置・文字サイズを保持する。英語は行分割可能な語境界を優先し、長い語は字形クラスタ境界で分ける。日本語はUnicodeの行分割境界を優先する。入力の明示改行は保持する。折返し境界の空白は行末・行頭に描画せず、コピー時には改行となる。一般段落の意味構造復元や自動文字サイズ変更とは区別する。

一定字体・一定行送りの対応ブロック、回転や傾斜のない横書き、1〜64行・4096文字以内、行送り0.5〜4倍を対象とする。先頭・末尾の空白、空行、タブ等は理由付きで拒否する。1字形クラスタも入らない幅、ページやグループBBoxからのはみ出し、非対応字体・文字、取消は非反映にする。原本、別の文字・共有呼出し、画像、フォーム、ページ座標を保持する。Undo/Redo、保存・再編集は既存の文書状態を使う。

幅の判定にはPDFのWidths/Wと、必要な場合は既存の標準14字体幅表を使い、画面描画用の丸めによる改行差を避ける。PDF4QTの固定ソースを変更せず、同じCore DLL内の小さな読取りブリッジだけを公開する。変更後の実字形範囲も指定幅とページ／グループの範囲へ照合する。

単純な一定幅Courierによる英語の語境界と長い語、日本語Meiryo UI、幅変更、再編集、共有Formの本文、拒否・取消の条件を製品操作前に固定する。別PDF処理系で期待行・文字・部分字体埋込み・幅・他要素・変更範囲外の画素を検査する。ネイティブIME・複雑な段落・混合字体・任意の回転・縦書き等は別評価とする。元の正解や閾値は変更しない。
