# 本文の選択・コピー：実装設計

2026-10-04。[閲覧設計4.4・V06/V07](VIEWER_UX.md)を具体化するM1内の改修。SPEC・ACCEPTANCEの正解・受入条件は変えない。以下の内部構成と操作細部は実装判断であり、製品の全対応範囲やAcrobatに対する優位性の承認ではない。

## 操作と不変条件

通常のドラッグは文字位置を始点・終点とする範囲選択とする。逆方向も同じ文字範囲になり、行・ページをまたげる。PDF4QTの文字レイアウトで得た読み順を利用し、任意の段組みを単純な座標順へ並べ替えない。コピーと字形の強調には同じ文字索引を用いる。

ドラッグ中、上下左右の画面端へ近づけると距離に応じてスクロールする。スクロール後のページ変換を毎回使い、開始時の画面座標を使い回さない。ページ間の余白では近いページの端へ範囲を伸ばす。マウス解放・Esc・別文書・revision変更・配置開始・ウィンドウ非アクティブで自動スクロールを止める。署名ドラッグでは本文用の自動スクロールを開始しない。

選択後のCtrl+Cと右クリック「コピー」は同じ内容とする。選択なし、権限なし、文字解析中／失敗なら既存のクリップボードを上書きしない。文字解析中にCtrl+Cを押しても後から勝手にコピーしない。選択範囲の全ページが揃ってから利用者のコピー操作を受け付ける。画像のみのページでは文字のない偽ハイライトを作らず、OCR案内を出す。

選択された範囲のUnicode文字は書き換えない。行区切りは改行、非空のページ間は空行1行で区切る。CropBox外の文字はコピーしない。未選択の本文や署名を混ぜず、PDF・dirty・文書編集Undo・表示履歴は変更しない。

## 責務と資源

`SelectionTextCache`は不変PDFからページ単位の文字列・字形矩形を一つのワーカースレッドで読み出す。GUIの押下・移動・描画でPDF解析を行わない。表示ページを優先し、選択に必要なページを追加する。世代を照合し、別文書やOCR／Undo前の遅延結果は破棄する。キャッシュは通常16MiBを目安とし、選択中のページは範囲の整合性のため保持する。能動的に大量選択した場合のメモリは文字量に比例し、プロセス全体の上限保証とはしない。

文字の論理範囲はページとUTF-16文字境界。境界はUnicodeの書記素境界へ合わせ、サロゲート等の途中を切らない。CanvasはPDF点から最も近い文字境界への解決、選択範囲の描画、自動スクロールを担当する。コピー可能状態と短い説明は文書状態表示に併記する。読み取り専用の理由を隠さない。

上流のPDFSelectTextToolは同一ページ内のドラッグを前提とし、別ページで範囲を消す。上流の文字レイアウトと読み順を利用しつつ、範囲状態と必要ページの読み込みを独立した部品で補う。上流ソースは改変しない。

## 実行する検証

固定済みのviewer-search、D01、D02、D03-OCR、D10を使う。事前の正解を保持したまま、単ページ・複数行・前後方向・ページ境界・回転・CropBox・UserUnit・スクロール後の座標・空白／画像ページ・署名との優先順位を確認する。範囲取消、別文書／Undo／OCRのrevision切替、コピー権限、無選択時のクリップボード保持も扱う。PDFとUndoの不変を検査する。

自動試験はWindows Qt offscreenで行い、マウス移動中のイベント応答、ページ読み込み回数、保持バイト数を記録する。OSクリップボード・OS入力は別確認で、合成イベントを実操作と呼ばない。ダブルクリックの単語選択、文字カーソル操作、Narrator、縦書き・複雑な段組みの改善は今回の実装範囲に加えない。
