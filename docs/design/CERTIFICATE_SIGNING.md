# 証明書で署名したコピー

M5の拡張。既存の文字・画像による見た目の署名と、保存済み署名の検証を維持する。現在の未保存変更を含むPDFから、新しい証明書署名付きコピーを作る。元の保存先、原本、編集履歴、Undoと未保存表示を変更しない。成功したコピーを別ウィンドウで読み取り専用として開き、検証入口へ到達できるようにする。

入口は「作成→証明書で署名したコピー」。ローカルのPFX/P12、パスワード、理由と新しいPDF保存先を指定する。証明書のSubject・Issuer・期間・SHA-256指紋を先に表示し、その証明書での署名を明示確認してから実行する。署名は不可視の標準AcroForm署名欄として追加し、ページの見た目は保持する。見た目の名前・画像署名は既存ツールで配置できる。原本や既存の保存先へ上書きしない。

今回の範囲はPKCS#12ファイルにある1組のRSA 2048bit以上／EC 256bit以上の秘密鍵と証明書、SHA-256のadbe.pkcs7.detached承認署名。秘密鍵の不一致、期限切れ・有効期間前、署名禁止のKeyUsage、MACがない／パスワードが違う／破損したP12、未対応の方式を拒否する。P12は4MiB、証明書チェーン16件、CMS64KiB、出力PDF256MiBを今回の境界とする。失効・信頼できるタイムスタンプ・LTV・DocMDP認証署名・署名後の追加承認・ハードウェア鍵／OS個人ストアは未対応と表示する。自己署名の作成を本人性の保証とは呼ばない。

暗号化・既存の証明書署名・保持不能フォーム等の編集制限を解除しない。既存フォームのFields、入力値・初期値・外観、本文、注釈、リンク、しおり、OCR情報、ページ座標を保持した候補へ署名欄を追加する。既存AcroFormを作り直して項目を消さない。通常保存の変更として署名を付けない。

P12とパスワードはこの操作内でだけ使い、証明書ストアへの登録・アプリ設定への保存・ネット送信を行わない。生の秘密鍵をファイルへ書き出さない。P12と元PDFのファイルが途中で更新されたら候補を確定しない。入力中に証明書・パスワードを変更したら、以前の確認を失効させる。

実装は現在の文書のスナップショット、署名欄と固定長予約領域、正確なByteRange、CMSの生成、原本と同じボリュームの私有保存候補、再読込・暗号的な署名対象一致・指紋・ページ／保持の検査、上書きしない確定を分ける。署名値を差し替えた後はPDFライターで再保存しない。失敗・取消は候補を整理し、既存ファイル・元文書を保持する。

実装前の試験条件：正常RSA／ECの新規コピー、原本と未保存署名・Undoの保持、既存フォーム6種類とV/DV/AP、日英OCR検索・コピー、本文／注釈／しおり／ページ座標の保持を確認する。独立した.NETによるCMS検証とPDFエンジンによる表示・抽出、署名付きコピーの編集制限、証明書指紋の一致を検査する。間違ったパスワード、鍵不一致、証明書期間・用途、壊れた／過大P12、既存署名・暗号化拒否、保存先競合・実書込拒否、途中の入力更新と取消を、省略せず結果に残す。試験秘密鍵は合成文書用だけを新しい私有試験領域に生成し、利用者の証明書を探索・使用しない。
