# 拡大したPDFの移動操作

2026-10-05。[閲覧設計4.4・V07](VIEWER_UX.md)を具体化するM1の閲覧改修。受入条件・既存入力・正解は変えない。

左上の閲覧操作に「選択」「手のひら」を並べ、押下状態と本文カーソルで現在の操作を示す。手のひらでは、ページ・署名・ページ間の余白のどこからでも左ドラッグで表示を移動する。画面上の移動量をそのまま使い、文書座標や署名の座標は変更しない。端で止まった後の逆方向操作には余分な戻し量を要求しない。

小数の論理ピクセルはイベントごとに切り捨てず、端数を次の入力へ持ち越す。高DPIでのゆっくりした移動も失わないよう、0.4 DIPを25回重ねた変位が10 DIPとなることを合成入力で検査する。実OS倍率での入力確認は別に残す。

本文にフォーカスがある場合、修飾キーなしのSpace押下中だけ一時的な手のひらにする。キーの自動反復で切り替えを繰り返さない。Space解放時はドラッグを止め、元の選択／手のひらへ戻る。確定済みの文字選択は一時移動で保持する。入力欄・IMEのSpaceは横取りしない。

ツール切替・Esc・フォーカス喪失・非アクティブ化・非表示・resize・文書更新で進行中のドラッグを確定せず取り消す。署名のドラッグ中にSpaceへ切り替えても編集Undoを追加しない。Escは選択ツールへ戻る。明示的な手のひらはフォーカス移動後も維持し、一時Space状態だけを解除する。新しいPDFと署名配置の開始では選択へ戻す。

Canvasが入力と既存スクロールAPIを接続し、Windowは操作ボタンと状態表示だけを担当する。別の描画・PDF解析経路やタイマーを追加しない。閲覧操作はPDF・dirty・編集Undo・表示履歴を増やさず、読み取り専用・OCR処理中も使用できる。

実装後はD02の回転・CropBox・UserUnit、D10のページ境界、署名との競合、読取専用、入力欄、Space反復・途中解放、Esc・フォーカス等の取消をWindows Qtで試験する。最小画面の実描画も確認する。合成イベントと実OS操作を区別し、Native IME・実OS倍率・物理入力・Acrobat比較を未実行のまま合格とはしない。
