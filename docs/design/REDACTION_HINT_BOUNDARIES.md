# 墨消し後に残すTrueType点番号と命令長の境界

2026-10-12。dev38の閉じた命令文法を変えず、成功側のPUSHWを実PDFで検証するための固定条件。一般TrueTypeヒント、一般M5、配布候補更新の合格ではない。既存原本・正解・失敗記録は変更しない。

既存hinting-v1の成功入力は最大187実点であり、成功する字形命令にPUSHWが含まれない。拒否のPUSHWだけで保持成功を実証した扱いにしない。新しいhint-boundaries-v1は既存partial-text/visible.pdfとshared-fonts-v1の固定SHAを生成前に照合する。Noto埋込字体の利用条件を引き継ぎ、追加文書内容と重複点の処理はCC0の合成試験とする。字体全体のライセンスをCC0へ変更する意味ではない。

保持する既存文字の単純字形で、最初の座標とon/off-curve flagを複製して最初の輪郭へ加え、すべての輪郭終点番号を増分移動する。元の最後の点と全輪郭の座標順序・形状・bbox・advanceは維持する。新しい点配列を製品出力から正解にせず、生成済み入力を独立検査の正解とする。点番号255には256実点、256には257実点、32767には32768実点を用意する。両軸はy→xで閉じ、各軸の点0と最後の実点をMDAP[1]しIUPする。短い255はPUSHB[1]、256と32767はPUSHW[1]だけを使用する。

拒否条件は、実点が十分ある場合でもPUSHWの0x8000と0xffffが負数へ符号拡張されること、実点数と等しい正の番号が最初のphantomであること、255のPUSHWが非正規であること、PUSHWの切断であることを別入力で固定する。空輪郭に非空命令を置く入力も拒否する。空の命令列を持つ通常輪郭は成功側に残す。

4096 bytesの成功列はy軸の1点とx軸の1022点をすべて正規PUSHWで渡す。軸開始・IUPが合計4 bytes、点操作が1023×4 bytesとなる。4097 bytesはy軸に昇順の3 PUSHB点、x軸に1021 PUSHW点を置く。命令文法・実点範囲は正しいまま、命令長だけが上限を超える拒否にする。元字体maxpの私的値は正解にせず、保持命令と実輪郭からmaxpを独立算出する。

共有使用は別ページ、別名字体、兄弟Form、N/R/D注釈外観の代表入力を含める。既存の資源参照・展開ハッシュ照合と原本からの共有閉包再構築を維持する。除去字形だけの私的命令markerを別成功入力へ入れ、残る文字・必要な共有字形の保持と、除去字形・元字体・元対応表・私的markerの不在を別々に確認する。共有字形が正当に残る場合に単字そのものの不在を要求しない。

独立検査はPDFium/pypdfの文字と位置、fontToolsの全保持輪郭・命令・maxp、全到達/展開ストリームの復元不能性を調べる。位置は既存0.5pt、PDFiumとPopplerの72/96/300dpiは既存1px境界外の差0、対象外ページは全画素一致を維持する。低DPIのヒントが入力描画に実際の効果を持つことも確認し、他の字形のヒントだけでPUSHWの観測を代用しない。取消・未知命令拒否・未保存署名・Undo・保存後再編集は製品側の実Qt試験で確認する。

CVTは今回の境界入力には導入しない。次の限定拡張ではSVTCA→正規PUSH点→正規PUSH CVT番号→MIAP[1]→IUPだけを候補とし、元cvtの偶数長・符号付きFWORDと参照範囲を確認する。保持字形と必要な複合子字形の参照番号だけを収集し、番号の昇順で新cvtを作り、命令内の番号を再符号化する。元表全体、未参照値、除去字形専用値を保持しない。stack上限は実際の最大2へ再算出し、命令長も書換後の値で算出する。prepは既存の空/固定dropoutだけ、fpgm・CVT書込み・RCVT・演算・制御フロー・storage・zone変更・複合自身ヒントは引き続き拒否する。同じ値が残る共有使用から必要な場合は、その必要値の存在と削除文字列の不在を区別する。未使用値へ埋めた私的markerの不在、未知命令の非反映拒否、低DPI描画保持を先に固定する。

根拠：[Microsoft TrueType命令仕様](https://learn.microsoft.com/en-us/typography/opentype/spec/tt_instructions)、[cvt](https://learn.microsoft.com/en-us/typography/opentype/spec/cvt)、[maxp](https://learn.microsoft.com/en-us/typography/opentype/spec/maxp)。命令の限定文法と固定入力についてだけ評価し、任意prep/fpgm・CFF・可変字体・一般CMap・DR/DA・一般共有Formは未完了とする。
