# フォーム入力データの読み込み・出力（M5）

M5の次の機能単位として、既存AcroFormの入力値をローカルXFDFへ出力し、既存文書へ読み込む。これはフォームの新規作成とは別の実装範囲で、SPEC・TECH・ACCEPTANCEと元の正解・閾値は変更しない。

## 操作と文書の意味

「作成→フォーム入力データ」から出力／読み込みへ入る。出力は項目と値を確認して新しい`.xfdf`ファイルへ書き、原本・保存先・未保存状態・Undoを変更しない。XFDFには入力値が平文で含まれることを短く説明する。暗号化文書ではコピー許可が必要で、PDFの暗黙の平文保存とは区別する。PDFやデータを外部へ送信しない。

読み込みは現在のPDFへ対応する項目名・現在値・読み込む値を一覧表示し、利用者が明示適用する。値の検証と外観の作成をすべて済ませた候補だけを1回のUndoとして反映する。取消・失敗・未知項目・不正値では一部を反映しない。元の署名・注釈・ページ・しおり・リンク・OCRを保持し、保存後もフォームの再編集と印刷を可能にする。読取専用の文書へは適用しない。

## 形式と今回の境界

XFDFの名前空間`http://ns.adobe.com/xfdf/`、`fields/field/value`を扱う。[Adobeの形式例](https://guides.adobe.com/coldfusion/en/docs/install-and-configure-coldfusion/__references__/populating-a-pdf-form-with-xml-data.html)。項目の識別は完全修飾名で行い、表示用のTUや同じ表示ラベルを識別子にしない。対応する6種類の入力欄と複数選択を扱い、ラジオの共有値を1項目へまとめる。階層を持つfieldも完全修飾名へ対応させる。

XFA・署名値・送信アクション・注釈データ・リッチテキストは今回のXFDF値入出力には含めない。対応しない項目を一覧で示し、出力から除いた種類を無言で成功扱いにしない。PDFへの参照情報は開かず、外部ファイルやURLを参照しない。DTD・外部エンティティ・未知の変更要素は拒否する。4MiB・500項目・階層16の処理上限を先に置き、超過を明示する。空白・改行・日本語を勝手に正規化しない。

## 実装前に固定する検証

- 6種類・日本語・複数選択・空欄・改行・XML特殊文字を出力／読込し、入力値を保存後のpypdfと独立XMLパーサーで照合する。
- 階層名・同じ表示ラベル・複数widget・ラジオ共有値を区別し、表示名を宛先にしない。
- 実ダイアログの一覧・明示適用・1回Undo／Redo・取消・新しいデータ出力・失敗後の再試行を実行する。小さい画面でも主要操作を保つ。
- 未知／重複項目、選択値・文字数・禁止文字の不正、readonly・署名・暗号化入力への適用、DTD／不正XML／外部参照／上限を検証する。途中に有効な変更があっても一部を公開しない。
- 原本ハッシュ・署名・注釈・OCRと保存・再編集・外部表示を確認する。出力は既存ファイルを上書きせず、競合・取消・NTFS失敗で保持する。
- M1〜M5の回帰と通信権限なしを実行し、ReaderでのXFDF取り込み・ネイティブ入力・実容量不足など未実行は区別する。
