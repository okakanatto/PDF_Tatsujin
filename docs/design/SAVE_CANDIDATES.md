# 中断された保存候補の寿命

保存先と同じファイルシステムへPDF候補を作成し、解析・検証後にWindowsの置換を行う既存設計を維持する。原本を途中書き込みしない。TECH `5が求めるクラッシュ後の掃除は、アプリ所有と識別できるものだけを対象にする。

## 対象と操作

保存中の強制終了では通常のRAIIによる一時領域の削除が動かない。次に同じフォルダへ保存するとき、本アプリの新しい保存候補を作る前に、中断された候補だけを整理する。保存先のPDF、原本、Undo、未保存変更を掃除対象にしない。保存先一覧や署名内容を永続ログへ記録しない。

新しい候補のフォルダ名は `.pdf-tatsujin-save-XXXXXX` とし、固定版の所有マーカーとプロセスのロックを含む。所有マーカーはロック取得後に書き込む。正常終了・保存失敗時はロックを解放して既存の私有一時領域を除去する。

## 除去条件

- 直下の候補名が一致し、フォルダと中の全項目が通常ファイルである。リンク・ジャンクション・サブフォルダをたどらない。
- 所有マーカーが版を含めて完全一致する。許される中身はマーカー、`save.lock`、`candidate.pdf`だけ。未知の項目があれば保留する。
- Qtの実プロセスロックを取得できる。時間だけで実行中の保存を期限切れにしない。ロック取得後にも対象を照合する。
- 承認済みの二ファイルだけを削除し、ロックを解放した後に空のフォルダだけを除去する。再帰削除で後から追加された項目を消さない。候補の走査は一回128件までとする。

以前の版のマーカーがない保存候補、壊れたマーカー、未知のファイルを含む候補は保持する。整理に失敗しても、新しい保存先へ正常に候補を作れる限り保存を続ける。旧試験の中断候補は証拠としてそのまま保持する。

## 意味と検証範囲

候補は保存トランザクションの一時出力であり、クラッシュしたプロセスの未保存作業を復元する自動保存ではない。中断後の再保存時に、完成した候補も上記条件を満たせば整理する。電源断、すべてのタイミング、すべてのファイルシステムへの保証はしない。

通常・例外時の除去、実行中の保存の保持、無関係なファイル／壊れたマーカー／未知項目の保持を自動試験する。別プロセスで実際の保存を開始し、候補作成直後とPDF書込後に強制終了して、原本・保存先の保持と次回整理を試験する。実容量不足試験は専用VHDで別途行い、未実行なら未実行と記す。
