# ページ入力と集中表示

2026-10-05。既存の[閲覧設計](VIEWER_UX.md)の4.1・4.5と画面骨格を、M1の連続ビューアへ実装する。SPEC・TECH・ACCEPTANCEの要件・正解・閾値は変更しない。以下の割り当て・幅は実装上の初期値で、個別にユーザー承認済みとは扱わない。

ページ番号は下部に常時置く。Ctrl+Lで入力、Enterで物理ページへ移動、Escで現在の番号へ戻す。PageLabelsは既存の状態表示に併記し、入力や印刷範囲とは区別する。1から総数までの半角数字以外はその場で説明し、丸めたり移動したりしない。入力中のスクロールで未確定入力を上書きしない。IMEの未確定文字は移動指示として扱わない。

集中表示は本文でF8、または下部ボタンで切り替える。OSの全画面にはせず、文書ツールバーと左右パネルを畳む。下部のページ入力・倍率・前後の表示履歴・解除・OCR取消を残す。解除時は開いていた設定とナビゲーションのタブを復元する。Escは配置・選択・手のひら等の取消を先に扱い、操作が残っていない場合に集中表示を解除する。入力欄のF8で読書モードを切り替えない。

ツールバーを隠しても文書コマンドのショートカットはウィンドウへ登録し、開く・保存・印刷・Undo／Redoを利用可能にする。入力欄の編集UndoはQtのShortcutOverrideを優先する。RedoはOSの既定に加えてCtrl+Shift+Zも使える。

幅1200論理px未満で右設定を開くと左のページ・しおりパネルを畳み、右設定を閉じると左を戻す。検索タブは設定と併用中も残す。Ctrl+Fは集中表示を解除し、検索欄を見せてフォーカスする。設定を開く明示操作と文書切替でも集中表示を解除する。パネルの開閉で中央のPDF点を保持し、文書・未保存状態・編集Undoを変えない。閲覧履歴はページへ実際に移動した場合だけ登録する。

本文ではCtrl+Home／Endで先頭／末尾、Ctrl+Plus／Minusで拡縮、Ctrl+0で全体、Ctrl+1で幅を合わせる。Plusを入力するためのShiftも受け付ける。入力欄の同じキーは入力操作を優先する。初回のネイティブウィンドウはタイトルバー・タスクバーを除く表示領域に収める。OS設定を変更せず、後の利用者によるリサイズは尊重する。

PageControlは入力・検証とフォーカスを所有し、PDFにはアクセスしない。Windowはページ移動・表示履歴・パネル状態を所有し、Canvasの既存PDFアンカーで配置変更後の位置を復元する。文書保存・OCRワーカーの実装は変更しない。

実行前の検証条件：D10の物理1〜100ページ、空欄・文字・0・101・負数・長い数値の拒否、Esc・入力中スクロール・IME未確定、PageLabelsと物理番号の区別。D02の4方向回転とUserUnit混在で開閉後のPDFアンカー軸誤差2論理px以下、1024×720と1280×850で下部の入口が画面内にあることを確認する。実OCR中にも集中表示・ページ入力・取消を操作し、取消前の文書と未保存署名を保持する。OS入力・実DPI・第三者の体験評価とは区別して結果を残す。
