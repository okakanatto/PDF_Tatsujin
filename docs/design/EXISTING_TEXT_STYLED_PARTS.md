# 本文の文字部分を選んで編集する追加範囲

従来の均一な段落編集とは別に、字体が途中で変わる本文の文字部分を一覧と実ページで明示選択し、元の字体を保持して置換・削除する。最初の対象はページ直下のBT/ET内で、各Tj/TJの前に独立した明示Tmがある横書きの本文。各文字部分の開始位置が固定されるため、文字数の変更や削除で後続の文字部分を移動させない。元の段落編集の混合字体拒否と固定試験を維持する。

1ブロック64描画・4096文字、ページ1000ブロックを上限とする。字体とサイズは描画ごとに異なってよい。位置・サイズ・書体変更、相対位置による流し込み、改行数変更、自動折返し、Form内、縦書き、不可視OCR、文字クリップ・透明性、レイヤー・構造タグはこの操作で扱わない。文字間隔・単語間隔・文字上げは0、水平比率100%。非対応の位置命令や確認できない字形・文字対応は理由を示して非反映にする。文字の削除は墨消しではない。

置換は元の字体の符号化と候補の再解析を照合する。部分埋込み字体は元の文字部分で確認したコードだけを再利用できる。候補の文字がページからはみ出す、元は重ならなかった別の文字部分と重なる場合は拒否する。原本・未保存変更・未選択本文の文字／字体／字形位置、画像、フォーム、注釈、ページ座標を保持する。適用は1回のUndo、取消・世代更新・外部更新の検査は既存の候補ワーカー経路を使う。

実装前に別の合成入力を固定する。Latinの標準／太字の隣接部分、TJの字間、部分埋込み日本語、Tf省略の後続ブロック、CropBox・UserUnit・回転、画像・フォームを含む。複数の部分の置換・削除、保存再読込と再編集、Undo/Redo、キャンセル、古い候補、元の段落方式の拒否、相対流し込み・不明文字・重なり・ページ外の拒否を試験する。独立PDFium・pypdfで検索・抽出と未選択文字の座標を検査し、PDFium・Popplerの300dpi描画では選択した元／新字形の範囲以外に差分を認めない（境界1画素）。元の入力・正解・閾値は変更しない。

これは明示座標を持つ文字部分の追加範囲であり、一般の混合字体段落編集やM6全体の完了ではない。実機IME、OSクリップボード、外部利用・出荷評価は別途追跡する。

終盤取消の対象試験で既存本文CollectorのAfterOperationからの例外がプロセスを異常終了させた。固定PDF4QTは同コールバックをnoexceptのscope guardから呼ぶため、後処理の取消・整合エラーを共通ContentCallbackGuardで保持し、次の命令開始または終了検査で安全に拒否する。例外による巻き戻し中は後処理を呼ばない。同じ境界を共有Form画像の解析にも使い、全取消コールバック段階の非反映を検査する。上流ソースやpinは変更しない。異常終了版exeと途中結果を保存し、早期／終盤取消、原本非反映を再試験する。

独立検査の最初の結果ではPDFiumの自動生成空白を未選択字形として比較してFAILになった。診断で相違はFPDFText_IsGenerated付きの面積ゼロ空白1個のみ、実文字・元の描画命令・字体資源・両エンジン範囲外画素は一致した。元のFAILを保持し、PDF中の実文字（明示空白を含む）は座標完全一致のまま、自動生成された空白／改行だけを生成フラグで識別して別記録にする。生成された非空白は検査自体を拒否する。入力・正解・画素閾値・境界は変更しない。
