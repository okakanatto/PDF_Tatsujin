# スキャンの部分墨消しと、その後の文字認識

画像だけのスキャンPDFは、文字認識の前に画像画素の一部分を除去し、新規コピーへ保存できる。そのコピーを同じアプリで日英OCRし、範囲外の文字を検索・選択・コピー可能にする。既存OCR層の一部分を捨てて再認識する方式は採らない。既存文字層の部分指定の拒否条件と、通常保存の意味を維持する。

初回試験では黒い矩形をOCRが架空の文字として読み、隣の固定語「管理事務所」も誤認識した。認識用の画像だけで、黒の塗りつぶしパスが軸に平行な単一矩形であり、その内側の全画素が実際に黒である場合に背景へ置換する。白い文字・部分的なクリッピング・透明色等で非黒画素が残る場合は置換しない。矩形数1000とページ画素数2倍の検査上限を持つ。出力PDFの黒い矩形と元画像の消去は変更せず、OCR前後の表示一致を固定条件のまま再検査する。

認識用の矩形境界は保持するため、固定入力では境界付近の1文字にOCR誤認識が残る。対象語不在・範囲外の固定語・画素保持の合格と、認識全文の完全一致は区別する。観察した全文と初回FAILはローカル実行記録に保持する。

実行前の条件は `fixtures/redaction-copy/scan-then-ocr.json` に固定する。D03の日本語3ページ目と英語7ページ目を使い、原稿の市民公園の字形位置から定めたPDF座標の矩形を除去する。対象語は1箇所。範囲外の管理事務所・花壇・coastal・surveys、英語ページ上の日本語署名を保持する。元資料と固定正解・閾値を変更しない。

実際のコピー画面で範囲を描き、数値入力と明示確認で新規保存する。保存後のコピーで実OCRを完了し、新しいPDFへ通常保存、再読込、日英検索とQt文字選択・コピーを実行する。原本・未保存状態・Undo／Redoは保持し、対象文字を復元できる元画像を出力へ残さない。

独立PDFium／pypdf／Popplerで、OCR前後の対象語不在・範囲外の検索語・署名・ページ座標、対象画像の内部画素、元画像の展開データ不在、固定した矩形の外側の画素一致を検査する。描画比較は300dpiで行い、境界に1ピクセルだけの描画差を許容する。元のスキャンを保持する検査と、OCRの表示が墨消し済み画像から変わらない検査を分ける。原稿に対する品質や任意の共有画像・未知属性の安全性を一般化しない。OSクリップボード・ネイティブ画面は実行するまで未実行。
