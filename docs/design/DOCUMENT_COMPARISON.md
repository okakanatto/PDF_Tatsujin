# 文書比較（M5）

継続指示に沿う次の拡張。既存SPEC・TECH・ACCEPTANCE・入力・閾値を維持し、Acrobat全機能同等を意味しない。現在の未保存状態を含むPDFと別のPDFを、同じアプリから読み取り専用で比較する。元文書と比較先、保存先、Undoを変更しない。

固定PDF4QTのPDFDiffは本文描画を抽出し、IgnoreOptionalContentを使ってMediaBoxに基づく比較を行う。標準の注釈・フォーム外観を含む実表示との比較を先に成立させるため、今回は既存の回転・CropBox・UserUnitを考慮した描画を再利用する。比較処理、結果のデータ、結果を見る画面を分け、新しい外部依存は追加しない。

## 操作と対象

「作成→PDFを比較」で比較先を指定し、必要なパスワードを非表示欄へ入力して開始する。両文書のコピー許可を確認する。証明書署名や暗号化された文書も、許可された読み取りのみで扱う。外部アクションやJavaScriptを実行しない。処理中も取消ボタンを保持し、入力変更・失敗・取消では古い結果を最新として見せない。

ページの追加・削除・対応と、見た目・抽出文字・標準フォーム値・注釈内容の変化を一覧で表示する。左右のページを並べ、変化した画素の範囲を強調し、ページのない側は「対応ページなし」と示す。文字の比較は元の空白・改行を保持する。スキャンPDFは見た目、OCR済みPDFは見た目と抽出文字を対象にする。しおり・文書情報の違いは文書全体の項目に分ける。対象外の添付ファイル内容・JavaScriptの挙動・タグ構造・レイヤー表示設定・XFA・表示widgetのないフォーム等を、比較済みと表示しない。

対応付けは「共通ページに合わせる」と「同じページ番号」を選べる。共通ページは表示・抽出文字・フォーム・注釈の完全一致を基準に、順序を保つLCSで対応させる。一致するページ間で残るページは順序に沿って対にする。同じ見た目が繰り返される場合や大きく変わったページの対応は自動判断に限界があるため、左右のページ番号を結果に明示する。ページ移動を確実に認識したとは表示しない。

比較範囲の「差がない」はPDFの全バイト・全意味の同一保証と区別する。画素は72dpiで正確に比較し、印刷解像度の完全同一とは表示しない。片側500ページ、1ページ1600万画素・抽出文字20万文字、合計抽出文字1000万文字を処理上限とし、超過を部分成功として扱わない。各ページの照合データだけを保持し、全ページの画像をメモリへためない。結果のプレビューは選択した対だけを非同期で描く。文字の読み順を構築する前に、SDKと同じ非空白文字の最小文字数を計数して上限超過を拒否する。その後も抽出結果の空白・改行を含む正確な文字数を検査する。

結果は新しいJSONファイルへ明示出力できる。文字・フォーム値・注釈内容を含む平文であることを表示する。既存ファイルは上書きせず、専用候補・原子的確定を使い、取消・競合・書込み失敗では既存先を保持する。比較先の読込前後ハッシュを照合し、結果を開いている間のファイル更新も出力時に検出する。

## 実装前の試験条件

寸法・座標の比較は既存保存精度の条件に合わせて1e-6ptを許容し、描画した画素と抽出文字は完全一致で判定する。標準注釈はページ当たり1万件、文書情報の文字列は項目当たり65536文字、出力JSONは64MiBを上限とし、超過は失敗にする。
文書情報の比較データは片側4MiB、フォーム・注釈の比較データは両文書合計32MiB以内とし、各項目の追加前に計数する。画像は選択対だけ、プレビューも片側1600万画素以内で最大144dpiを使う。独立PDFiumとは変更の有無と対象ページを一致させ、文字・画像等の同寸法ページの差分範囲は各辺2px以内で照合する。

- 同一文書と通常保存した同一内容は差なし。本文文字・日本語署名・コメント本文だけの変更、画像・図形・回転・CropBox・UserUnit・フォーム入力値・リンク宛先・しおり名・文書情報の変更を検出する。各試験の変更箇所と期待する種類を先に固定する。
- ページの追加・削除、同じページの繰り返し、共通ページの前後の変更とページ番号方式を確認。ページ対・追加・削除が固定した正解と一致することを検査する。
- 実日英OCR後の比較で、文字の保持と変更検出を確認する。両文書の全オブジェクト・履歴・保存先・原本ハッシュを保持する。
- 不正PDF、誤パスワード、コピー禁止、入力更新、500ページ／画素／文字数の上限、途中取消、既存出力・確定競合・NTFS拒否。部分的な結果を成功にしない。
- 実ダイアログの入力・失敗後再試行・取消、コンパクト表示、左右の結果と差分強調、選択変更時の古いプレビュー破棄、JSON出力を実行する。独立PDFiumで変更箇所を描画し、pypdfで原本保持とJSONの正解を照合する。
- 全回帰・通信権限なし・配布物実展開を実行。未実行のネイティブUI・OS倍率・Reader GUI・物理印刷・クリーンWindows・実容量不足・初見／Acrobat比較は別に追跡する。
