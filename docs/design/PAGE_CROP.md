# ページの余白・表示範囲の調整

M4の次の文書整形機能として、選択したページの見える範囲を狭める。共通座標の回転・CropBox修正後に実装する。文書の本文・画像・署名・注釈・フォームとMediaBoxを保持し、変更はCropBoxだけとする。これは墨消しではなく、見えなくなった情報もPDF内に残る。通常のPDF保存と再編集を維持する。

## 操作

ページ整理でページを選び「余白・表示範囲を調整」を開く。プレビューする選択ページ、見た目の上・右・下・左から除く長さをmmで指定する。現在のCropBoxを基準とし、回転後の用紙の上下左右へ同じ物理mmを適用する。プレビューには残す範囲と除く範囲を示し、現在・変更後の用紙寸法を表示する。異なる大きさの複数ページにも適用できるが、全ページの妥当性を先に検査する。拡大・自動余白検出は今回の操作へ含めない。

入力は0〜500mm、負・非有限を拒否する。変更後の両辺は1mm以上必要。入力0は変更なしとし、Undoを増やさない。プレビューは所有する別スレッドで1ページだけ縮小描画する。前の描画が終わる前に別ページを選んだ場合は、最新の要求だけを次に描く。全ページの描画データを保持しない。

適用は全ページを検査した候補をDocumentへ1回commitする。Undoで全選択ページを同時に戻し、Redoできる。ダイアログの取消・プレビュー失敗・無効範囲で文書を変更しない。読取専用と処理中の文書は拒否する。未確定フォームは既存の確定経路を通してから文書スナップショットを取る。適用後はページ数と参照情報を保ち、新しい用紙範囲へ表示を更新する。

## 実装前の確認

| ID | 入力・操作 | 条件 |
|---|---|---|
| M4C01 | 固定D02の0/90/180/270、CropBox原点、UserUnit=2へ非対称のmm指定 | 独立したPDF座標の期待値と0.000001pt以内。選択外、MediaBox、本文、注釈辞書と署名のメタデータを保持。保存・再読込・署名再編集・Undo/Redo |
| M4C02 | 無効ページ・重複・負・非有限・上限・小さすぎるページ・保護文書・取消 | 全体を拒否し、原本と未保存変更を保持。無効な後続ページがあっても先行ページを変更しない |
| M4C03 | 製品のページ整理からプレビュー・変更・適用・Undo | 回転した選択ページでも見た目とmmを照合。GUIイベント処理、1回のUndo、取消、ゼロ入力、選択外保持。OS入力の未実行と区別 |
| 独立検査 | 保存した派生PDF | pypdfでCropBox・MediaBox・回転・UserUnit・本文・フォームを検査し、PDFiumとPopplerで表示・文字情報を確認。ページ全体を画像化しない |

既存の全回帰と画像入出力・共通座標の独立検査を再実行する。要件・正解・閾値は変更しない。ネイティブIME・OS倍率・Reader GUI・クリーンWindows・実容量不足・物理印刷は別に未実行を追跡する。

## 保存時の数値

独立検査で、固定PDF4QTの実数保存が小数5桁へ丸め、mm指定の保存後誤差が0.0000043307ptとなることを確認した。事前の0.000001pt条件は維持し、実数保存だけを小数10桁へ変更した派生ソースをビルド領域へ作る。元のサブモジュールを変更せず、元ソースと派生手順のhashを依存ロックで照合する。通常保存全体に適用されるため既存の全回帰も再実行する。

ファイルに保持する座標の精度と、各ビューアが計算・表示する精度は区別する。[Adobe PDF Reference 1.7の実数構文と付録C](https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/pdfreference1.7old.pdf)は旧ビューアの実装上の精度を記載しており、今回のファイル精度を全ビューアの演算精度として保証しない。PDFium・Popplerで互換表示を検査し、Reader GUIは未実行として追跡する。
