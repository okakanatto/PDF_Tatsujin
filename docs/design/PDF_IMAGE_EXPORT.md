# PDFを画像として出力する

M4の2番目の実装単位。通常のPDF保存と区別し、PDFの見た目をPNG／JPEGへ書き出す。元PDFの文字情報・フォーム・証明書情報は出力画像へ引き継がれない。PDF原本、未保存変更、Undoと閲覧位置は保持する。M1〜M3の要件・正解・閾値は変更しない。

## 操作と境界

「作成」のメニューから「PDFを画像として出力」を開く。現在ページを既定とし、全ページ・指定ページへ切り替えられる。既存の出力フォルダ、名前の接頭辞、PNG／JPEG、75〜600dpiを確定する。物理ページ番号を4桁以上の連番へ含め、一覧で出力結果を確認する。JPEGは白い用紙に品質95で出力する。

CropBox・回転・UserUnitを反映する。用紙寸法にdpiを掛けた表示画素数は、既存のrenderPageと同じ整数丸めを使う。出力は用紙上の可視注釈・署名・入力済みフォームを含む。PNGは描画画素を可逆保存し、JPEGは圧縮による差があることを表示する。コピーが許可されていないPDFはUIと文書層の両方で拒否する。

1回に1〜128ページ、1画像64メガピクセルまで。超過を黙って縮小・省略しない。本文の解析・描画・符号化は別スレッドで1ページずつ実行する。未確定フォームは既存の確定経路を通してからスナップショットを取得する。出力自身を編集Undoへ追加しない。

## 保存・取消・失敗

- 既存出力を上書きしない。設定確定時に全出力先を確認し、重複、既存ファイル、入力不正は出力前に拒否する。
- 出力先と同じフォルダに、既存の私有一時領域を作る。全ページの描画・符号化・検証が終わるまで公開しない。中止・描画・符号化失敗では完成画像を出力先へ追加しない。
- 完成画像はWindowsの置換しない移動で1ファイルずつ確定する。確認後に他のプロセスが同じ名前を作っても上書きしない。公開途中の取消・競合では既に確定した画像を保持し、成功・失敗・未出力を個別に示す。全体成功と表示しない。
- 通常終了では所有する一時領域を削除する。強制終了や実容量不足の評価は別に追跡し、未実行を合格にしない。

## 実装前の確認

| ID | 入力・操作 | 確認 |
|---|---|---|
| M4E01 | 固定D02のCropBox・回転・UserUnit、PNGとJPEG | 物理寸法から求めた画素数・dpi情報・出力順を確認。PNGは描画画素と完全一致、品質95のJPEGは固定D01の描画参照で平均絶対チャネル差3以下。元PDF・署名・注釈を保持 |
| M4E02 | 取消、既存ファイル、公開時の外部競合、無効範囲・名前・dpi・保護PDF | 原本・既存保存先を保持。公開前の取消は画像追加なし、途中の競合は成功／失敗を個別報告。量の上限を緩めない |
| M4E03 | 製品画面で範囲・名前・形式を選択して出力 | 作成中にもGUIのイベントを処理し、結果と再試行へ到達。文書・Undo・未保存状態・閲覧位置を出力前後で照合 |

PillowでPNG／JPEGの読込・寸法・dpiと画素を検査し、Popplerの参照描画とページの方向・可視内容を照合する。既存の全回帰と画像からPDF作成の5件も再実行する。ネイティブOS入力、Explorer、Reader GUI、物理印刷、実容量不足は別の未実行項目である。
