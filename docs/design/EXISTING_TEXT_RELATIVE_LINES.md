# 相対位置で改行する本文

既存のT*による一定行送りに加え、文字描画の間の `0 dy Td` と `0 dy TD` を扱う。dyは負の有限数で、同じブロックの全改行が同じ命令・同じ値を持つこと。初期位置は従来どおり1個のTm。横書き・一定の字体・1〜64行・4096文字まで。元と同じ行数の置換、明示的な書体変更、ブロックの位置・サイズ、削除と保存後の再編集を扱う。

改行命令は書き換えない。位置・サイズは初期Tmを変え、改行を含めたブロック全体へ作用する。TDが設定した行送りも後続の本文へ保持する。横移動、不均一な行送り、途中の字体変更、複数Tm、Form内部、縦書き、OCR層などは明示的に拒否する。原本や未保存状態への部分反映はしない。

実装前に合成CC0入力と期待文字・操作・境界を別のcriteria.jsonへ固定する。TdとTDの置換、日本語書体変更、移動、削除、Undo/Redo、通常保存・再読込・再編集を実アプリで試す。拒否入力は横移動と3行の不均一な行送り。PDFium・pypdf・Popplerで未選択文字と座標、画像、フォーム、ページ座標、変更範囲外の画素を独立検査する。既存の正解・閾値は変えない。ネイティブIME・外部GUI・一般段落の再配置を評価済みとしない。
