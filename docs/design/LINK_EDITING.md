# リンク編集

M4の文書整形として、標準PDF Link注釈を追加・変更・削除する。本文の編集や外部サイトの閲覧はこの機能に含めない。

## 操作

「作成 → リンクを編集」で同じ文書の編集画面を開く。ページ選択、リンク一覧、実PDFのプレビュー、選択したリンクの設定を配置する。「範囲を描いて追加」を選んで用紙上をドラッグすると、新しい矩形リンクを作れる。既存リンクをクリックして選び、中央をドラッグして移動、右下のハンドルでサイズを変更できる。見た目の左・上・幅・高さをmmでも指定できる。小さな画面では設定をスクロールし、適用とキャンセルを常に表示する。

移動先は文書内の物理ページ（ページ全体表示）またはhttp/httpsのWeb URL。新規リンクは境界線なし、説明は任意。既存リンクは「元の宛先を保持」を既定にし、明示的に選び直すまでは倍率、名前付き宛先、未知アクション、複合アクションを保持する。作成したURLを自動で開かず、既存の安全な閲覧方針を継続する。

一覧とプレビューは文書の候補だけを編集する。適用に成功した時だけ全変更を1回のUndoとして反映する。キャンセル、入力不正、処理失敗では元の文書・未保存変更を保持する。保護・証明書署名付き文書の編集禁止も継続する。

## データと保持

独自ファイルは不要。標準の`/Subtype /Link`、`/Rect`、`/Dest`または`/A /URI`、Unicodeの`/Contents`を使う。ページと注釈配列の元の位置で既存要素を識別し、他の注釈の順序とオブジェクトを保持する。既存リンクの未知属性、外観、枠、色、フラグも保持する。範囲変更時は既存QuadPointsを同じ比率で移動・拡縮し、不正な形状は黙って矩形化しない。

回転、CropBoxの原点、UserUnitを含む共通変換を使い、画面上の実寸ptとPDFの座標を往復する。新規または範囲変更したリンクは表示範囲内で幅・高さ1pt以上。既存リンクの範囲外配置は変更しない限り保持する。上限は全文書1000リンク。超過・重複・壊れた参照は部分編集せず通知する。入力のURLは厳密に解析し、資格情報・制御文字・空ホスト・http/https以外を拒否する。

## 実装前に固定する試験

- 新規、日本語説明、文書内／URL宛先、移動・サイズ・削除、1回Undo／Redo、通常保存、再読込・再編集。
- 4回転、非ゼロCropBox、UserUnit。期待するPDF矩形の差は1e-6pt以内。独立PDFエンジンのリンク矩形と宛先でも検査。PDFiumの単精度座標APIは期待値を同じ単精度へ変換し、差1e-6pt以内で比較する。
- 既存の名前付き／未知／複合アクション・QuadPoints・直接辞書、他の注釈・本文・フォーム・OCR文字の保持。
- 不正URL、範囲、ページ、重複識別、上限、破損形状、処理中取消。原本ハッシュと作業前状態の保持。
- 実際のQtウィジェットとドラッグ操作、プレビュー切替、コンパクト画面、文書内リンクによる実際のページ移動。外部サイトは実行しない。
- M1〜M4の既存回帰と独立保存後検査。ネイティブ操作・外部GUIが未実行なら区別して記録する。
