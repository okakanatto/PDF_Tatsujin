# 本文の改行数を変える追加操作

従来の「文字を置換」は元と同じ行数を維持する。追加の「改行を変更して置換」で、対応する横書きブロックを手動で1〜64行・4096文字以内に組み直す。各行には文字が必要。行送りは文字サイズに対する倍率として明示し、初期値1.375、対応範囲0.5〜4.0。自動折返し・段落の自動再配置は扱わない。

ブロック先頭の位置・文字サイズを保持し、新しい文字描画をT*による改行で出力する。元の字体を保つか、許可された対応書体を明示選択する。元ブロック終了時の字体と行送りを戻し、後続の本文へ状態を漏らさない。プレビューは変更後の字形・範囲に追従し、はみ出し・未対応文字・非対応構造では適用不可にする。明示適用まで原本・未保存文書・履歴を変えず、1回のUndoと通常PDFへの保存・再読込・再編集を扱う。

追加の固定条件ではTd／TDの2行から3行への日英置換、3行から1行への再編集、1回Undo/Redo、字体・行送りの継承、既存画像・文字・フォーム・ページ座標の保持を検査する。空行・65行・範囲外の倍率・取消を拒否して非反映を確認する。固定入力・期待文字は製品操作前に保存する。既存の正解・検索語・閾値は変更しない。独立したPDFium・pypdf・Popplerで文字・周辺座標・変更範囲外の画素と継承する状態を照合する。実行まで合格と記載しない。
