# 1行内の混合字体と字送り

文字部分編集に「後続の文字を送る（1行）」を明示選択する追加モードを設ける。1個のTmから始まる横書きBT/ETで、複数のTj/TJを同じ行へ描画し、途中のTfによる字体・サイズ切替を保持する。選択部分を元字体で置換・削除し、同じBT/ET内の後続部分だけをPDFの字送りに従って移動する。前の部分、他のブロック、別のForm呼出し・別ページを変更しない。元の独立位置モードと段落の混合字体拒否は維持する。自動折返し・改行数変更・位置／書体変更はこの追加モードに含めない。

適格条件は、先頭に1個の明示Tm、64描画・4096文字以内、相対Td/TD/T*や途中のTm・描画命令の混在がないこと。字間・単語間隔・文字上げ0、水平比率100%、正の字体サイズ、通常の塗り・不透明な文字・横書き、確認できる文字対応と字形に限る。共有Formは既存の明示opt-inと選択枝の複製を使用する。行全体の元字形・候補字形がページと全先祖FormのBBox内に収まることを確認する。複雑clip・透明グループ・循環・レイヤー・構造タグ・未収録文字等は理由付きで拒否する。削除は墨消しではない。

各部分の描画前後の文字行列・CTM・字体を記録し、選択開始位置と先行部分が変わらず、後続の原点と字形が選択部分の字送り差だけ平行移動することを検証する。浮動小数の加減算照合は既存BBoxと同じ1e-8ptの算術境界を実装前に定め、独立検査の正解座標は完全一致を要求する。移動する行全体が他の元は重ならなかった文字ブロックに重なる場合は拒否する。行内の字体・Unicodeは完全一致し、候補は再解析後だけ適用する。

製品操作前に別の合成CC0入力と正解を固定する。通常・回転/CropBox/UserUnit・2階層共有Form・資源継承で、標準／太字／部分埋込み日本語・TJの調整・字体省略の後続ブロックを含める。各部分の置換、削除、保存・再編集、2番目の共有呼出し、Undo/Redo、全取消段階、元／新BBox超過、途中位置指定・相対改行・字間・未収録文字を検査する。実UIではモードの明示、行内の後続移動、削除後のプレビュー枠、拒否回復と非反映を確認する。

PDFium・pypdfで検索・文字対応、元字体、未選択ブロック／別呼出しの座標・資源保持を独立検査する。固定入力と正解文字から独立符号化・置換した正解PDFの全ページ画素と実文字座標をPDFium／Popplerで完全一致させる。300dpi・境界1px・移動する行の元／新字形領域外0を維持する。製品出力から正解を作らない。ネイティブIME・OSクリップボード・DPI・外部実機・出荷評価は未実行を追跡し、一般段落・一般M6の完成は宣言しない。
