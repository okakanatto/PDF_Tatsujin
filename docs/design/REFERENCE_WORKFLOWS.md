# 閲覧中の参照パネルと検索結果

SPEC F01のページ・検索・文字操作と、既存のしおり・表示履歴を小さい作業領域でも使えるようにする。正本PDF、検索の正解、OCR精度、受入閾値は変更しない。

## 操作の決定

- 左側を自動収納しているときも、下部の「参照」からページ・しおり・検索へ到達できる。通常クリックで現在のタブを開き、メニューで参照先を選ぶ。文書がないときは無効にする。検索のCtrl+Fも同じ入口へつなぐ。
- 狭い画面では、利用者が明示的に選んだ左タブを自動収納しない。新たに右の設定を開くと従来の自動配置へ戻し、入力途中の設定は作り直さない。検索と右設定を同時に使える既存の経路は維持する。
- 検索結果はクリックまたはEnterで本文へ移動する。選択済みの結果を押し直した場合も、スクロールして離れた本文からその位置へ戻る。キーボードの上下による結果移動も維持する。
- マウスによる結果選択の途中では本文へ移動せず、クリック確定時に一度だけ実行する。選択モデルの変更とクリックの両方から重複して履歴を増やさない。同じ位置への再表示だけなら表示履歴を増やさない。
- 参照パネル、表示履歴、リサイズは文書の変更状態や編集Undoを変更しない。OCR中や読取専用でも参照でき、元文書・未保存署名・入力途中の設定を保持する。

## 実装の境界

Windowは参照パネルの表示意図と画面への移動を担当する。SearchPanelは結果の選択・確定を担当し、QListViewのポインターイベント中とキーボードによる変更を区別する。検索結果モデルやPDF描画・保存の責務を追加しない。

## 検証

既存のviewer-navigation／viewer-searchの入力と期待結果を維持し、800×480、960×540、1024×720、1280×850で参照パネル・未保存署名・設定入力の保持を確認する。選択済み結果の再クリックとEnter、一度の戻る、PDFと原本の保持、検索結果の幅変更を実Qtウィジェットで試験する。実OCR中の参照と取消も確認する。

Qt offscreenと合成入力をネイティブIME・実キーボード・OS倍率の合格にしない。初見操作やAcrobat比較は第三者による別の評価として残す。
