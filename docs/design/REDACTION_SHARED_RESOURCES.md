# 共有字体の墨消しコピー

2026-10-11。dev24の固定条件を維持し、対象外ページ・Form・注釈外観で同じ埋込み字体を使うPDFを拡張する。一般公開やM5全体合格の条件は変更しない。

対象範囲だけの文字列・画像を除去する。対象外に同じ単字があれば、その単字を保持する。元字体や元ToUnicodeを丸ごと残す代わりに、各使用箇所の残る字形と文字対応を再構築する。元資源の参照と展開ストリームの一致を手掛かりに、別名や独立した複製字体も追跡する。未知の属性・別名への元資源の残留を許可する例外は作らない。

ページ資源は局所化し、ページ木の継承資源も到達経路から除く。Formは自分の資源と軸に沿う行列を持つ既存対応形式を扱う。範囲外では文字や位置を変更せず、パスも描画命令として保持する。注釈外観の既知のN／R／Dと状態辞書を再構築する。編集可能なフォームのDR／DA等の対応が確認できない場合、最終資源監査で拒否する。

共有された元画像や、削除語を含む元Form内容が対象外にも残るケースは、元情報を保持して成功にしない。未知の参照、循環・深すぎるForm、継承が確認できない資源、未評価字体／透明性等は失敗時非反映を維持する。処理は私有builder内で行い、固定点到達後に既存の全到達資源監査と未使用回収を実行する。

追加合成入力・正解を実装前に固定する。同一字体の複数ページ、別名、複製ストリーム、ページ木継承、未使用参照、対象外単字、兄弟／入れ子Form、注釈外観を含める。PDFium／pypdfの文字保持、fontToolsの輪郭、文字位置0.5pt以内、PDFium／Poppler300dpiの範囲外画素差0（既存の1画素境界）を要求する。元字体／対応表／対象内容の展開データは出力に残さない。取消・拒否時は原本・未保存状態・Undo・保存先を保持する。旧固定入力・失敗証拠は変更しない。

追加の `shared-followup-v2` で同じFormを2ページの異なる範囲に指定すると、2ページ目に削除語が残る旧出力を再現した。Formの局所指定範囲を参照と展開内容のhashごとに照合し、異なる指定は拒否する。全体除去したFormの子Formも除去対象として追跡する。独立した複製Formの範囲外使用も拒否する。原本・固定指定・失敗出力・旧exeは保持する。生成中に失敗したv1は試験入力にせず、固定条件を完成させたv2だけを使用する。
