# 混合字体の各行内の字送り

dev37で実装する固定プロファイル。既存の独立位置と1行モード、一般本文・墨消しの受入条件を維持する。

先頭Tm1個のBT/ET、2〜64行、計64個以内のTj/TJ、計4096文字以内。各行は複数の字体・サイズを持てる。改行はT*、0・負のTd、0・負のTDのいずれか一定の命令・一定の正の行送り。T*は各改行直前のTLを検査する。先頭・末尾・連続改行、横移動、後続Tm、引用符、他の描画命令は非対応。各部分の実字体、符号、横書き、通常字間、Fill、alpha=1を確認し、元・候補の全字形がページと全祖先Form BBox内に入ることを要求する。

物理行番号を各描画部分へ割り当てる。元字体で選択部分の描画だけを置換・削除（削除は[]TJ）し、同じ行の後続部分だけを選択部分の終端の字送り差で動かす。先行部分、別行、別BT/ET、共有Formの別呼出し、別ページは保持する。全部分を再解析し、文字・字体・サイズ・CTM・行番号・行列の線形成分を照合。未選択部分の原点・終端・全字形はこの移動量と一致しなければ非反映。算術確認1e-8pt、独立の実文字座標は完全一致。変更行が以前重なっていなかった別行・本文へ新たに重なる候補も拒否する。選択した共有Form枝のみを複製し、資源の継承と全先祖クリップを確認する。

UIは既定の位置保持を維持し「後続の文字を送る（各行）」を明示選択する。行番号を表示し、プレビューの全枠は候補のoccurrenceに対応させる。改行の追加・行全体の折返しは含まない。削除は墨消しではない。取消、失敗、古いスナップショットは非反映、成功は1回のUndo/Redo。

新規CC0固定入力flowing-lines-v1を製品操作前に生成・SHA固定する。ページ、回転/CropBox/UserUnit、Td、共有2階層Form、資源継承の5入力に3行×4部分を用意し、中央行の英日4部分、削除、保存・再編集、共有2番目呼出しを確認する。初行・最終行の境界も確認する。原本と正解文字だけから独立符号化・枝複製を作り、全実文字座標、描画命令・字体・画像・フォーム・別ページを検査。PDFium/Popplerの300dpiで正解全ページと完全一致し、元・新の変更行だけの描画領域を1px拡張した外側の変更は0画素。元/候補から閾値や正解を作らない。既存の入力・正解は変更しない。

一般段落、縦書き、任意の行送り・複雑なクリップ／透過、ネイティブIME・OSクリップボード・DPI、Reader／Word、第三者評価、一般M6受入はこのプロファイルでは未実行／未達。
