# 共有Formの文字部分

独立したTmを持つ文字部分の置換・削除を、「グループ内の文字も表示」を明示した場合に共有Formへ広げる。元の字体を保持し、選択した呼出しからページまでの枝だけを複製する。別の呼出し・別ページ・画像・フォーム・未選択文字の位置を保持する。通常のページ直下モード、段落モード、既存の混合字体・相対流し込みの拒否条件は維持する。文字の削除は墨消しではない。

解析・候補検証の両方で、選択した文字部分の字形が全先祖FormのBBox内に完全に収まることを確認する。透明グループ・循環・明示クリップ・部分クリップ・不明な字体・相対位置・新たな文字重なりは理由を表示して非反映にする。資源を継承するFormも実際の呼出し時の字体を確認し、編集枝へ同じ資源を固定する。

実装前に合成CC0入力をstyled-form-parts-v1へ固定する。同じ2階層のFormを同一ページで2回、別ページで1回使用し、標準字体・太字・既存の日本語部分字体・TJ・後続の字体状態を含める。通常・回転/CropBox/UserUnit・資源継承の3入力について各文字部分、削除、保存・再編集、2番目の呼出しを試験する。BBox・循環・透明グループ・明示クリップ・取消を別途拒否試験する。

PDFiumとpypdfで実文字、命令、資源と枝の保持を独立検査し、PDFium/Popplerの300dpiで選択前後の字形領域（境界1px）外の差分0を確認する。PDFiumの生成した配置用空白だけを分離し、PDFに存在する空白も含め全未選択文字座標を完全一致で比較する。既存の正解・閾値を緩めない。実UIの2チェックボックス、別呼出し選択、プレビュー、拒否回復、Undo/Redo、保存・再編集を確認する。ネイティブIME・OSクリップボード・DPI・外部実機等は未実行を明記する。一般の本文編集・共有Form全体・出荷評価の合格を意味しない。

Popplerのヒンティング後の輪郭はPDFiumの輪郭と一致しない場合がある。固定入力と正解文字だけからpypdfで独立に符号化・枝を複製した正解PDFと字形だけの参照描画を生成し、エンジン自身の字形領域に境界1pxを適用する。製品出力を参照生成へ使わない。0画素条件を維持し、両エンジンで独立正解PDFとの全ページ画素の完全一致も要求する。初回FAILと診断を保持する。
