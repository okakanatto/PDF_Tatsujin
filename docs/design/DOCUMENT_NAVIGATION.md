# 文書内の参照をたどって戻る

2026-10-05。閲覧設計4.1・V08をM1で実装する。受入条件・既存fixture・OCR正解は変更しない。

左側に「しおり」を追加し、階層・全文タイトル・移動先の物理ページを示す。単クリックとEnterで移動する。移動可能な項目だけを実行し、宛先なし・名前解決失敗・非対応アクションは理由を表示する。PDFの起動時アクションは実行しない。

本文のリンクは選択ツール時の短いクリックで移動し、ドラッグは文字選択を優先する。署名枠・配置・手のひらはリンクより優先する。マウスを離した位置が同じリンク内にあり、移動量がOSのドラッグ閾値未満の場合だけ実行する。Esc・フォーカス移動・文書更新は保留したクリックを破棄する。

宛先は文書のページ参照から解決する。存在しない参照を先頭ページへ代替しない。名前付き宛先の循環を検出し、XYZ／Fit／FitH／FitV／FitRを扱う。BBox形式と複合アクションは未対応として明示する。外部リンク・別文書・Launch・JavaScript等は自動実行せず、外部リンクはクリック時に宛先と未対応の説明を表示する。

移動前のPDF点・倍率・表示モードを既存の「前の表示／次の表示」に記録する。無効な宛先は表示履歴を増やさない。内部移動・しおり表示・ページラベルでPDF・dirty・編集Undoを変えない。しおりを開いても本文の幅は変えない。

ページラベルは物理ページ番号に併記し、番号を置き換えない。読取専用・OCR中も閲覧でき、文書更新で古いしおりやリンクの参照を使わない。異なるPDFではしおりを入れ替える。

追加合成PDFと宛先・ラベル・リンクの正解を試験前に固定する。D07の既存しおり・外部リンク、追加文書の階層・名前付き宛先・回転/CropBox/UserUnit・XYZ null・矩形fit・無効参照、ドラッグとクリックの区別、表示履歴、署名/OCR/Undo/保存後の保持をWindows Qtで実行する。ネイティブ入力・実OS倍率・Readerの未実行項目は継続する。

実装の境界として、表示倍率は既存の25〜400%に収め、文書端ではスクロール可能範囲へ制限する。しおり表示は1万件・64階層までとし、上限に達した場合は表示する。ページラベルは数値オーバーフローを避け、ローマ数字10万超・繰返し英字2600超の異常に長い表記は物理番号へ戻す。ラベル未対応を保存内容の変更で代替しない。BBox宛先、外部リンクを開く操作、集中表示、文字カーソル選択、アクセシビリティの実評価は残課題とする。

実行中に固定版PDF4QTがアクションの`/Next`を保持しないことを確認した。元のしおり・リンク辞書を共通アダプターで検査し、複合アクションの最初だけを実行しない。しおりのUIは宛先の値を受け取り、Windowが移動と表示履歴を所有する。結果は[M1の実行報告](../testing/M1_NAVIGATION.md)へ分けて記録する。

2026-10-09追記：倍率の境界は[自動フィットの設計](AUTOMATIC_FIT.md)で更新した。手動の25〜400%と、フィット・PDF宛先・履歴の計算済み倍率を区別し、後者はレンダラーの8〜6400%を使う。[参照操作の設計](REFERENCE_WORKFLOWS.md)では、狭い画面のタブ選択・固定位置の入口・検索結果の再選択・重複しない表示履歴を具体化している。M1時点の境界説明と現在の実装を区別する。
