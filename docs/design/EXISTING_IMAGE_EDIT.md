# 既存PDFの画像を編集する：M6の最初の範囲

拡張ロードマップの既存本文／画像編集から、ページ本文にある画像の移動・サイズ変更・PNG/JPEGへの差替え・削除を先に扱う。既存本文の文字列を再生成せず、画像を描く対象の命令だけを書き換える。同じ画像を複数箇所・ページで使う場合も、選んだ1回の描画だけを変える。変更は明示適用で1回のUndoへ反映し、通常PDFとして保存後も再編集できる。

初期対応はページ直下のImage XObjectを描く命令と、有限・可逆の行列に限る。Form XObject内部・インライン画像・非対応クリッピング・レイヤー・構造タグ等は対応済みと表示しない。対象画像と交差する既存OCR文字層がある場合、または移動先が既存OCRと交差する場合は、文字層の位置や内容と一致しなくなるため明示拒否する。保護・証明書署名の既存制限を維持する。画像編集を墨消しとして案内しない。

初回の固定入力には、画像と離れた位置にも不可視の文字があった。不可視文字があるページ全体を一律に拒否する実装では、その画像も編集できなかった。入力とFAILを保持し、対象画像との交差を検査する。Form内の不可視文字も別の文字解析で調べ、画像から離れた独立した文字を除去しない。別途、実OCR済みの固定合成入力を拒否条件へ追加して、OCRと重なる画像を変更しないことを検査する。

実ページと画像一覧を同じ画面に表示し、対象・ページ・現在位置を示す。ページ上の対象とmmの位置・サイズを確認し、元の縦横比を保つ操作を既定にする。移動・差替え・削除は保存前に取り消せる。失敗・取消・入力更新で候補を反映しない。

保存では選んだ画像命令を独立したq/Qと行列で囲む。他の内容・書体・フォーム・注釈・ページ座標と描画順序を保持する。差替えは専用の新規XObject名を使い、元リソースの共有箇所へ波及させない。元画像の資源が未使用で残る場合があり、削除後の機密情報除去はこの機能の目的と区別する。

縮小後に元サイズへ再編集する独立検査で、行列を小数10桁へ丸めると画像内部の描画が変わることを確認した。画像命令の行列は小数17桁で書き、指数表記を使わない。元のページ属性・書体・未選択命令を書き換えて補正しない。画像の配置境界では1描画ピクセルを除外し、元配置へ戻した結果は全ページの画素一致を検査する。RGBAの差替えは抽出した全バイトとアルファの完全一致を検査する。

実装前に、共有画像の複数描画、後続本文・図形・フォーム、回転／CropBox／UserUnit、日英本文を持つ合成入力と判定条件を固定する。試験は移動・サイズ変更・差替え・削除、Undo／Redo、通常保存・再読込・再編集、同じ資源の範囲外描画、原本不変、未対応の明示拒否を含む。独立PDFエンジンで文字・フォーム・注釈・幾何・画像配置を照合し、変更範囲外の表示を画素比較する。実画面の操作性とAcrobat比較は実行前に合格扱いにしない。
