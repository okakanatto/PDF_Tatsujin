# ヘッダー・フッター・ページ番号・透かし

M4の実装前に置く操作・検証条件。既存SPEC・ACCEPTANCEの条件は変更しない。

「作成」メニューからヘッダー／フッター、透かしを開く。現在／全体／指定ページを選び、1ページのプレビューを見て適用する。ヘッダーとフッターは左・中央・右の6欄、ページ番号は `{page}`、総ページ数は `{pages}`。開始番号は1〜999999、番号は開始番号＋物理ページ位置。指定範囲の連番へ黙って読み替えない。保存した番号は固定し、ページ整理後に自動更新しない。再適用時に計算する。

文字は日本語対応を含む既存の埋め込み可能な書体選択を使う。サイズ、色、四辺の距離（mm）を指定する。透かしは中央配置、角度と不透明度を指定する。文字を収められないページ、欄同士の重なり、未対応文字、未知の変数、不正な範囲をエラーにし、自動縮小や切り捨てをしない。ヘッダー／フッターは単行各200文字、透かしは単行200文字。6〜144pt、四辺0〜100mm、透かし角度−90〜90度・不透明度5〜100%。対象1〜1000ページまで。

位置と大きさは回転後のCropBoxを物理ptへ変換した座標で決める。0／90／180／270度、CropBox原点、UserUnitを含め、文字の読み方向を画面上で揃える。本文、既存署名、注釈、フォーム、OCR文字層、ページ寸法は変更しない。重なりによって既存本文を見にくくする可能性はプレビューで示す。透かしは前面の文字であり、墨消しや改変防止ではない。

通常PDFの印刷可能なStamp注釈とベクターの外観（AP）を使う。日本語の使用文字をフォントに埋め込み、対応Unicode情報を残す。PDF内の専用バージョン付き設定にグループID・元の入力・書体等を保存する。署名のメタデータとは区別する。保存後はこのダイアログでグループを選んで変更・全削除できる。グループ変更はそのグループだけを置き換え、他のグループと署名には触れない。結合後に複数グループがある場合も選択して編集する。設定が壊れた独自注釈は無言で削除しない。

全対象を検証してから候補PDFを作り、成功した場合だけ一度commitする。適用／変更／削除はそれぞれ1回のUndo。プレビューと適用は所有するワーカーで実行し、プレビュー要求は最新設定へ集約する。取消・失敗・終了待ちでは元の文書と未保存変更を保持し、部分反映しない。

検証はD02の全回転・混在サイズ・原点・UserUnitで位置と読み方向を独立に確認する。保存前後の本文・既存注釈・フォームの保持、番号の固定値、対象外ページ、追加／変更／削除／Undo／再読込、取消と異常入力を実行する。PDFiumとPopplerで日本語の表示・位置・方向・透明度を確認し、旧スキャンOCRとの併用と既存回帰も実行する。Qt offscreenの操作はWindows実画面・IME・Reader GUI試験とは区別する。これら未実行項目を合格に含めない。
