# 墨消しコピーの操作と実行基準

M5の内部候補を同じ文書ウィンドウの操作へ接続する。初版SPEC・ACCEPTANCEの正解と閾値は変更しない。現在の未保存状態を含むスナップショットから新しいPDFを作り、元の文書・ファイル・Undo／Redoは保持する。通常保存には適用しない。

「作成→墨消ししたコピー」で実ページを表示し、範囲を描く・移動・サイズ変更・削除できる。左上原点のmm数値欄とマウスの両方を使え、回転・CropBox・UserUnitは共通pageMatrixでPDF座標へ変換する。全ページの範囲一覧とページ選択を持つ。範囲・保存先の変更は確認選択を解除する。指定中に削除済みと表示せず、明示確認後の新規コピー保存でのみ適用する。

文書内のInfo／XMP・添付等の隠れた情報も整理されることを表示する。対応できない内容命令・字体・共有資源等は理由を示し、出力を確定しない。ページ全体の画像化、白い矩形、対象外の字形の削除で代替しない。暗号化・証明書署名の制限は保持する。対応範囲と未評価条件はREDACTION.mdに従い、操作の実装だけで一般文書の安全性を宣言しない。

保存はSaveCandidateへ書き、バイト列・ページ数・MediaBox／CropBox／回転／UserUnitを再読込して確認する。原本のハッシュを開始時と確定直前に照合し、上書きしないWindows確定操作を使う。保存済みコピーは別ウィンドウで開き、削除対象を含む元の履歴を持ち込まない。残る対応要素は再編集可能にする。コピー全体1000範囲・保存256MiBと資源検査の上限を持つ。

実行前に固定する試験：実メニューから範囲の描画・移動・サイズ変更・数値入力・取消と確認解除、新規コピー保存、保存後の検索とフォーム再入力、範囲外署名・元Undo／Redo・原本不変。既存の固定合成文書と日本語の可視／不可視字体入力を使用する。回転・CropBox・UserUnitの数値変換、狭いダイアログのスクロールと主要操作、処理中Escも確認する。

異常系：既存出力、入力更新（開始前・処理後）、保存先競合、取消（開始前・処理中・確定直前）、書込不可、未対応構造。生成の失敗を処理の拒否成功と扱わない。失敗時は既存ファイルと元状態を保持し、自分が所有する候補だけを整理する。独立したPDFium／pypdf／Popplerで出力の除去・範囲外保持を確認する。ネイティブIME／OS倍率・Reader画面・クリーンWindows・物理印刷・実容量不足は実行するまで未実行とする。

追加の実行条件：D03の固定された日本語3ページ目・英語7ページ目から2ページの文書を作り、実OCR後に日本語ページ全体だけを墨消しする。対象日本語の文字層と画像画素を除去し、範囲外の英語OCRの検索・Qtコピーと配置済み日本語署名を保持する。元のOCR状態・Undo／Redoは不変。Form XObjectは有効なBBox／Matrixの全体を含む場合だけ除去し、その依存資源も追跡する。一部指定、外部参照、任意のCMap等を対応済みと扱わない。範囲外のFormはBBoxのクリッピングを前提に原命令と資源を保持する。

Formの指定判定は、BBox／MatrixとページCropBoxによる有効な描画範囲を使う。実OCRの保存行列ではBBoxがCropBoxから数百万分の数ポイント外へ出る実例を確認した。指定範囲は広げず、PDFのクリッピングを判定へ反映する。対象のFormは一括除去し、CropBoxで見えない同一Formの内容と依存資源もコピーから除去する。これは範囲外の別Form・ページの削除とは区別し、一部指定は拒否する。原本と元の履歴は保持する。
