# 図形・罫線の墨消しコピー

2026-10-11。共有字体の拡張に続き、単色の塗り・線・Bezierを含むページを扱う。固定条件を先に追加し、既存の秘密語・位置・画素・取消条件を維持する。

対象外の図形・罫線は元命令を保持する。対象範囲に触れる図形は、塗り・線幅・線端・結合部を含む全体が指定内に入る場合だけ、そのパス構築命令と描画命令を除去する。黒塗りの下に元のパス座標を残さない。部分交差、幅0の線、明示clip、未描画パス、パス構築中の座標系変更は対象ページで拒否する。パターン・陰影・透明合成の対応範囲は広げない。

固定入力は文字の部分墨消しと、範囲外の色付き図形・線を併用する。塗り矩形、線端／結合部のある線、Bezier、複合パス、Formと回転・倍率を含める。PDFium／pypdfで文字と位置0.5pt、PDFium／Poppler300dpiで範囲外差分0、内容命令から対象の構築命令が消えることを検査する。失敗・取消は原本と保存先へ反映しない。対応外を合格扱いにしない。

往復して閉じた2辺のパスは、Qtのstrokerが長い結合部を作る実例を検出した。PDFiumの300dpiでは線は指定内にあり、入力・矩形を維持して修正する。線の結合部とmiter上限の扱いは [PDF 32000-1 §8.4.3.4–5](https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/PDF32000_2008.pdf) を確認し、上限超過はbevel、round結合は丸い端の外形で判定する。元のFAILと診断値を保持する。
