# 用紙に合わせる倍率と読書位置

SPEC F01の幅合わせ・全体表示を、小さいウィンドウでも実際のCropBox、回転、UserUnitに基づいて計算する。文書全体の倍率は共通とし、単にスクロールしただけで別の用紙へ再フィットしない。基準ページは最後に明示的に移動／フィットしたページのままとする。

## 倍率の扱い

手動操作の25〜400%という既存の試行範囲を、自動フィットへ適用しない。自動フィット、PDFに記録された宛先、表示履歴の復帰は、レンダラーが許す倍率を用いる。PDF4QTの安全範囲は8〜6400%であり、それを超える用紙・宛先まで無制限に表示できるという保証ではない。表示した倍率は下部に数値で示す。

自動倍率が手動範囲の外にある場合、相対的な＋／−やCtrl+ホイールで逆方向へ拡縮しない。範囲へ近づく方向には段階的に動き、外側へ進む方向は現在倍率で止まる。手動範囲へ戻った後と数値倍率を選ぶ場合は従来の25〜400%を使う。表示履歴は範囲外の実際の倍率も保持する。

Canvas内の倍率適用に明示的な方針を渡し、手動制限と計算済み倍率を区別する。PDF4QTが担当するCropBox・UserUnitの描画変換や正本PDFは変更しない。中央のPDF点、連続スクロール、基準ページ、表示履歴を既存の仕組みで保持し、サイズ変更を文書のUndoへ入れない。

全体表示の基準ページを見ているときは、読書位置の復元で四隅を見切らせない。復元後に収まるページの端だけを最小限移動し、幅合わせでは横方向だけを扱う。手動拡大表示の中央点は従来どおり保持する。連続スクロールで基準以外のページへ進んだ場合は、基準ページへ引き戻さない。

## 検証する操作

- 固定したD02の4ページについて、回転0／90／180／270度とUserUnit=2を含める。1280×850、1024×720、960×540、800×480、設定の開閉、幅／全体の組合せで、全体表示の四隅または幅表示の左右が領域内にあることを確認する。既存の2 DIPの表示丸め許容を維持する。
- 手動倍率で設定を開閉し、連続・同一イベント内のサイズ変更を挟んでも読書位置、ページ、倍率を保持する。
- 署名の入力途中、日本語変換の確定、未確定のページ番号、サイズ変更直後の明示的なページ移動を確認する。
- PDF、原本、文書の変更状態とUndoを保持し、署名・OCR・保存の回帰を実行する。

Qt offscreenでの実ウィジェット操作とQInputMethodEventは、ネイティブ日本語IMEやOS倍率100／150／200%の合格を意味しない。未実行の項目は別に追跡する。SPEC・TECH・ACCEPTANCEの正解と閾値は維持する。
