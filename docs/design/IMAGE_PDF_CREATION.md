# 画像からPDFを作成する

M4の最初の実装範囲。既存SPECのF01〜F08、ACCEPTANCEのA〜Cとその判定値を変更しない。以下は拡張操作の実装基準で、M4全体の合格やAcrobatとの同等性を宣言するものではない。

## 操作と保存の意味

- 「作成→画像からPDF」と起動画面の同じ入口から、PNG・JPEGを選ぶ。確認画面で一覧、選択画像のプレビュー、上／下へ移動、追加、除去を使い、一覧の順を確定する。1画像を1ページにする。
- 既定はA4、画像の向きに応じた縦／横、四辺10mmの余白、縦横比を維持して全画像を収める。切り抜き・画素の間引きはしない。画像の物理サイズを使う場合は、明示したdpiから用紙寸法を計算する。既定150dpi、選択75〜600dpi。画像内の曖昧なdpiを黙って採用しない。
- JPEGのEXIF方向を適用する。PNGの透明度をPDFの標準soft maskへ保持し、透明な場所は白い用紙に表示する。画像の復号後の画素をFlateで埋め込み、追加のJPEG再圧縮を行わない。RGB／グレーの静止PNG・JPEGを今回の検証範囲とし、色校正・CMYK印刷の一致まで保証しない。
- 作成は別の作業スレッドで行い、ページ単位の進捗と中止を表示する。全ページの作成・入力照合が完了したときだけ、新しい未保存の文書ウィンドウを開く。元のPDFウィンドウ、未保存署名、Undoを変えない。生成後は通常の署名・ページ操作・OCR・安全なPDF保存・再編集を使う。
- 入力を変更・削除しない。途中の破損、非対応、読込失敗、入力の外部変更、中止では完成文書を返さず、同じ一覧から修正・再試行できる。通常保存を画像出力へ置き換える機能ではない。

## 作業量の境界

アニメーションPNGはデコーダの最初の画像だけを採用せず、`acTL`宣言を検出して拒否する。チャンク構成は[W3CのPNG仕様](https://www.w3.org/TR/png-3/)を参照する。合成した2フレームAPNGも拒否試験へ含める。MPOなどの複合写真形式は今回の検証範囲外。

画像サイズの用紙は一辺14,400ptまでとする。越える場合はdpiかA4への変更を案内して拒否し、用紙を黙って縮めない。作成の中止はページ処理の境界で確認し、復号器を強制終了しない。選択画像のプレビューは縮小して1枚だけ保持する。

今回の作成処理は1〜128枚、1入力64MiBまで、1画像32メガピクセルまで、合計128メガピクセルまでとする。越える入力は理由を表示して全体を拒否し、黙ってページを落とさない。読み込み・復号は1画像ずつ進め、全画像の復号データを配列へ保持しない。QImageReaderの既定の割当上限を引き上げない。制限は実装・検証の境界であり、初版の既存PDF機能を狭めるものではない。

画像処理とページ生成は文書層、確認・進捗・スレッド寿命は専用ダイアログ、新しい文書を表示する責務はWindowに分ける。既存の画像署名とページ画像の埋込処理を共通化する。生成途中のPDFをDocumentのUndoへcommitしない。

## 実装前に固定する確認

| ID | 操作・入力 | 確認 |
|---|---|---|
| M4I01 | 縦・横のPNG、透明PNG、EXIF回転JPEG | A4方向、10mm余白、全画像、ページ順、画素寸法・透明度・向きを保持。独立PDFエンジンで表示し、抽出した画像を入力の復号画素と比較 |
| M4I02 | 画像サイズモード、異なるdpi | 72pt/inと明示dpiからMediaBoxを計算し、画像はページ全体に収まる。境界外・非有限の設定を拒否 |
| M4I03 | 一覧の並替え、既存PDFに未保存署名、新文書の作成 | 製品ダイアログを操作し、別の未保存文書へ一覧順で反映。既存文書・Undo・原本保持、保存・再開・追加署名・Undoを確認 |
| M4I04 | 作成中止、壊れた途中入力、非対応、欠落、量の超過、入力変更 | 部分文書を返さない。理由を表示し、元文書と全入力を保持。中止後に再試行できる |
| M4I05 | 日英のスキャン画像から作成、同じアプリで署名・OCR・保存 | 固定D03から派生した画像を使い、日英の事前固定検索語、コピー、可視画像と署名保持、保存後の独立表示を確認。D03と既存正解は変更しない |

全回帰A〜Cも実行する。画面なしQt試験、独立PDF検査と、未実行のネイティブIME・OS倍率・クリーンWindows・Reader GUI・物理印刷を区別して報告する。試験入力は合成画像と既存の公開用固定入力に限定する。
