# パスワードで保護したPDFコピー（M5）

利用者の全体ロードマップへの継続指示に沿い、M4の実装後にM5の暗号化出力を進める。これは今回の実装範囲の解釈と技術設計であり、M3合格やM5の全条件承認の意味ではない。既存SPEC・TECH・ACCEPTANCEを変更しない。

## 操作と文書の意味

「作成 → パスワードで保護したコピー」で、現在の未保存変更も含むPDFを新しいファイルへ暗号化して出力する。閲覧用・変更権限用パスワードをそれぞれ確認欄で入力し、印刷・コピー・フォーム入力・注釈変更・ページ整理・その他の変更の許可を選ぶ。パスワードは既定で非表示、明示切替で表示でき、履歴や設定・ログへ保存しない。必須のアクセシビリティ許可は維持する。

暗号化コピーの出力は、作業中の文書・保存先・Undo・未保存状態を切り替えない。既存ファイルを上書きせず、別の名前を案内する。保存候補を検証してから同じファイルシステム上で確定する。処理中取消・失敗・競合では原本と既存保存先を保持する。確定後は成功とし、取消したと表示しない。

暗号化／証明書署名付きPDFの読取専用と暗黙の復号禁止を維持する。コピーを開き直しても本アプリでは読取専用で、表示・検索・コピー・印刷は認証と許可に従う。既存の保護設定の解除や所有者権限での再編集は別の機能単位として追跡する。PDF/Aの暗号化は禁止されるため、PDF/Aの識別情報がある入力は通常PDFへの明示変換を実装するまで拒否する。

## 暗号化・文字

固定PDF4QTのStandard security handler、AES-256、V=5・R=6を最初に検証する。メタデータ・文字列・ストリームも暗号化し、RC4やR=5を出力しない。元の本文、画像、署名・注釈の再編集情報、フォーム値と外観、しおり・リンク、OCRを保持する。暗号化方式に合わせてPDF 2.0を明示する。

両パスワードは空を禁止し、PDFの準備処理後でも区別されることを確認する。UTF-8の127byteを超えた文字を黙って切り詰めない。固定SDKのSASLprep準備・Unicode・制御文字・双方向文字・境界を検証し、未対応や禁止文字を明示する。閲覧パスワードと変更権限パスワードの役割・権限値・実暗号化を別々に検査する。許可設定は対応ビューアが遵守する利用制限であり、認証済みソフトウェアがデータを取得できなくなる保証ではない。[qpdfの暗号化・権限資料](https://qpdf.readthedocs.io/en/stable/encryption.html)、[SASLprepの規則](https://www.rfc-editor.org/rfc/rfc4013.html)。

固定SDKでは鍵・salt・IVの生成にsecurelySeededの疑似乱数生成器を使う4箇所がある。固定ソースのハッシュと箇所数を確認するビルド専用アダプターでsystem生成器へ置き換える。QtのsystemはOSの暗号用途の乱数源を利用する。上流サブモジュールは変更しない。統計試験だけで暗号強度を証明したとは扱わない。[Qtの乱数生成器の説明](https://doc.qt.io/qt-6/qrandomgenerator.html)。

## 実装前に固定する試験

- 日本語とASCIIパスワード、空・同一／正規化後同一・不正文字・127byte境界・超過。誤パスワードとパスワードなしでは開けないことを確認。
- 本アプリと独立したpypdf／PDFiumでユーザー・所有者の認証、V/R/CF、メタデータ暗号化と権限を検査する。ファイルへ秘密のテスト文字列や元の展開ストリームが平文で残らないことを確認する。
- 4回転・CropBox・UserUnit、本文と可視画素、フォーム値・外観、日本語署名と注釈、しおり・リンク、実日英OCR文字を暗号化前と復号後で完全一致にする。標準PDFとして他のビューアから利用できることを確認する。
- 実ウィジェットのパスワード確認・非表示／表示切替・権限・出力、失敗後の再試行、取消、確定直前の保存先競合。原本ハッシュ、未保存状態、Undo、既存ファイルを保持する。
- 印刷／コピー許可の有無を本アプリで遵守し、認証済みでも編集・OCR・暗黙の平文保存をしない。証明書署名・既存暗号化・PDF/A入力は拒否する。
- 既存M1〜M4の回帰と通信権限なしで実行。実容量不足・Reader GUI・物理印刷等の未実行を明記する。
