以下の目的だけを伝え、ボタンの場所や操作手順の説明を先に読まずに試します。手助けした場合はその時点と内容を記録し、「説明なしで完了」に数えません。

1. `examples/D01.pdf`を開き、閲覧位置を変え、倍率を変え、読みやすい状態にする。
2. 同じ文書に日本語の署名を置き、位置を変え、変更を一度Undoする。新しいPDFへ保存し、開き直して署名を再編集する。
3. `examples/D03.pdf`を日英OCRし、認識した本文を検索・コピーし、新しいPDFに保存する。
4. OCR中の取消と未保存変更を伴う終了を試し、文書と変更がどう扱われたか確かめる。

各項目で、開始／終了時刻、完了した目的、迷った箇所、探した場所、意図と違った結果、手助け、保存先を記録します。時間の閾値や採点を実装結果に合わせて新設しません。試用者の指摘は改善事項として残し、見栄えや自動試験件数で使いやすさを判定しません。
