# ソース公開準備後の検証

2026-10-04、M1の既存Windows開発環境で実行しました。**M1全体の合格は引き続き保留**です。元の要件4文書、基準PDF、正解、検索語、閾値は変更していません。

## 変更した範囲

- 自作コードにMITライセンスを適用し、第三者部品の通知を維持。
- PDF処理、OCR、画面を別のCMake対象に分離。CanvasとWindow、PDF入出力・フォント・描画をファイル単位で分離。
- 試験を`tests/`へ移動し、`TATSU_ENABLE_SELFTEST`で組み込みを選択可能に変更。
- C++とPythonの書式を統一し、GitHub Actionsにソース検査を追加。
- PDF4QTを固定コミットのサブモジュールとして管理。大きな実行時資産は固定URLとSHA-256を検証して取得。
- 個人のPCパスをスクリプトから除去し、Visual Studioの検出とPopplerの環境変数指定に変更。
