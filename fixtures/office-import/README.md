# DOCX conversion inputs

Synthetic text and graphic inputs generated with python-docx 1.2.0, dedicated to CC0.
System font names are references; no system font program is embedded in the DOCX.
`criteria.json` and all input hashes were fixed before the first product conversion.
Do not regenerate these files to match converter output.

`simple.docx` contains Japanese and English paragraphs and a four-cell table.
`pages-images.docx` contains a lossless RGB image and an explicit page break.
The four negative inputs exercise macro, embedded object, external image and invalid ZIP rejection.
These inputs establish this limited path, not arbitrary Word layout equivalence.
