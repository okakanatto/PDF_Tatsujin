# 合成証明書署名PDF

`scripts/prepare-certificate-fixtures.py` で生成した公開可能なCC0の試験文書。実在の人・組織の証明書ではない。秘密鍵は保存せず、`test-ca.der` は試験プロセス内の信頼元としてだけ使用する。OSストアにインストールしない。

`manifest.json` に実行前の条件と全ファイルのSHA-256を固定した。正常なRSA／EC、未信頼・自己署名、期限切れ・有効期間前、本文／CMS改変、実際の増分リビジョン・2署名、6種類の不正範囲、空の欄・未知形式・結び付かない辞書、弱いハッシュ／鍵を含む。最初の19文書は変更せず、弱い暗号方式2件を追加した。

生成スクリプトは再生成時の条件を再現するが、鍵・CMS時刻・シリアルが毎回異なるため同じバイト列を再現するものではない。既存の文書・正解を上書きしない。通常の試験はこの固定した文書を使う。CAdES名の文書はCMSの検証入力であり、CAdESプロファイル適合試験ではない。期間試験は2026年の対象環境を基準にした入力で、2035年以降にはその期待値の見直しを別途記録する必要がある。
