# PDF/UA-1の機械検査入力

veraPDF corpusの固定コミットbb75f4f0073d9350dfd058c0162a367e6fadf25eから、バージョン識別と文字情報の既存pass／fail4文書を実装前に選定した。criteria.jsonとPDFのバイトは技術検証前の固定入力を維持する。機械検査の成功を、人による読み順・代替説明・読み上げ等を含む全PDF/UA適合と表示しない。元のM1〜M3条件を置換しない。

出典・帰属：[veraPDF corpus](https://github.com/veraPDF/veraPDF-corpus/tree/bb75f4f0073d9350dfd058c0162a367e6fadf25e)。上流READMEは[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)を指定する。原本PDFは変更せず、ファイル名だけを短縮した。上流パス・Git blob・サイズ・SHA-256と既存分類はcriteria.jsonに記録する。アプリのMITライセンスとは別である。
