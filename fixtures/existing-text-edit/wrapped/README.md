# 幅に合わせた本文折返しの固定入力

CC0-1.0の共有Form本文入力にCourier 12ptの2行を追加した合成PDF。UserUnit=2を保持する。英語の語境界・長い語、日本語Meiryo UIの期待行と幅、幅変更、再編集、共有Formの試験をcriteria.jsonで製品操作前に固定した。overflow-criteria.jsonのページ・グループBBoxからのはみ出し拒否も初回の該当操作前に固定した。

元の文字サイズと位置を保持し、選択箇所以外の本文・共有呼出し・画像・フォーム・ページ座標が変わらないことを独立PDF処理系で確認する。通常保存・再編集、Undo/Redo、取消・拒否と原本の保持を実アプリで確認する。折返し境界の空白は表示せず改行として保存する。文字削除を墨消しとして扱わない。

再生成はscripts/prepare-wrapped-text-fixtures.pyに新しい出力先を指定し、既存入力と正解を上書きしない。字体と第三者部品の条件は既存のfixtures・licenses通知に従う。
