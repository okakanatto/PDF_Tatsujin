# 共有Form本文の固定入力

この合成入力はCC0-1.0の既存グループ画像試験を基に、2階層の同じFormに一定字体の横書き2行を追加したもの。各原本のSHA、選択する最初の呼出し、日英の期待文字、Meiryo UI、改行と行送り、拒否条件はcriteria.jsonへ操作前に固定した。geometry-criteria.jsonは位置・サイズとBBoxを越える拒否入力を別に固定している。元のM1正解・検索語・閾値は変更していない。

選んだ1回だけの置換・字体変更・改行変更・位置とサイズ・削除、Undo/Redo、通常保存・再編集、表示範囲拒否・取消を確認する。他の同一Form呼出しと全画像・フォーム・ページ座標を保持する。実アプリ試験と独立したPDFium・pypdf・fontTools・Popplerによる文字・座標・字体・画素検査を組み合わせる。PDF本文の削除を墨消しとして扱わない。

再生成はscripts/prepare-form-text-fixtures.pyの新しい出力先を指定する。既存入力やcriteriaを上書きしない。フォントと第三者部品の条件はfixturesとlicensesの既存通知に従う。実文書を含まない。
