# 固定した合成試験文書

実務文書や個人の署名を含まない、M1の受入試験用コーパスです。PDFの由来、用途、ページ数、ライセンス、SHA-256は`manifest.json`にあります。基準の文字・検索語は`ground-truth.json`に固定しています。

自動試験ではGitに含めたPDFをそのまま使用します。再生成は試験の前提ではありません。生成スクリプトは`../scripts/make-fixtures.py`、追加の署名・診断文書は`make-signed-fixture.py`、`make-diagnostics.py`です。これらを再実行して既存の正解・入力を上書きしないでください。

D08-signedは試験専用の自己署名証明書による合成文書で、信頼された実務上の署名ではありません。秘密鍵は同梱しません。D11の低解像度・傾き・縦書き・段組み・表は診断用で、基準CERに含めません。

オリジナルの文字と図は[CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/)で提供します。埋め込まれたフォントには元のOFL等の条件が適用されます。フォント通知は`../licenses`にあります。
