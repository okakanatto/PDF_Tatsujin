# 既存画像編集の固定入力

画像・文章・フォームは試験用の合成データです。独自の文章と図形はCC0-1.0で提供します。実務文書・個人の署名・第三者の写真は含みません。埋込みのNoto書体はSIL OFL-1.1で、書体のライセンスは `../../licenses/` に保持しています。

`shared-images.pdf` は固定した `../redaction-copy/foundation/unsafe-source.pdf` に同じ画像の別描画と `../D01.pdf` の本文ページを追加したものです。PNG/JPEGは合成の差替え画像です。生成元と全入力のSHA-256は `criteria.json` に記録しています。

`ocr-associated.pdf` は固定した合成D03の3・7ページに、アプリで日英OCRと試験用の日本語署名を適用した結果です。M6の編集前に `ocr-refusal.json` で固定し、画像と重なる実OCR層を変更せず拒否する試験に使用します。

`ui-criteria.json` の最初の配置案は、UserUnit=2の原稿では不可視文字と交差します。この入力は保持して拒否試験に使用します。別の正例を `ui-positive-criteria.json` で最初のUI試験前に固定しています。失敗後に元の判定値を書き換えていません。

この入力の成功は、任意のPDFやAcrobatと同等の編集機能の合格を意味しません。Form内部、インライン画像、クリップ、レイヤー、タグ、OCRとの関連などの非対応条件は別途追跡します。
